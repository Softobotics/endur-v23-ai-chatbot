# endur-v23-ai-chatbot

1. Install the required dependencies:
```bash
pip install -r requirements.txt --upgrade
```

## Usage

Run the chatbot application with the following command:

```bash
streamlit run chatbot_v2.py
```

The application will open in your default web browser. You can start chatting by typing your messages in the input box and pressing Enter.

## Requirements

- Python 3.7+
- Streamlit
