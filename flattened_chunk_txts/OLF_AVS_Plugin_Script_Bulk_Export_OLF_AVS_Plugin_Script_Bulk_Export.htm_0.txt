 Section heading: Overview.
 Text content: This window is used to export both plug-ins and scripts. Plug-ins are exported into folders that are named after the project to which they belong. Scripts are exported as .mls files. In either case an XML config file (.xml) is generated that is used for bulk import by another user or for re-importing on the machine of origin. Note: (for V10.0r2 and later): When importing or re-importing scripts (.mls files) that were created using Bulk Export , use only the generated package .xml file. This is because a bulk exported file name includes path information for exported scripts that is used by the .xml file during import. The single .mls files should not be selected for Bulk Import because the treatment of file names can result in erroneous file names and duplication..
