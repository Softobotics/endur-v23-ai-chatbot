| 21 | The ticker file functionality (files ending in .tic) is not supported for new clients.  This functionality is in the system for backwards compatibility.  Here is the history:  This functionality was added a very long time ago.  At the time it was added, it worked with most deal types (Toolset/Instrument Types) in the system.  However, as new Instrument Types, and Toolsets were added, the functionality to produce ticker files was not updated.   Ticker files will get generated for most, if not all, toolsets, because it is generic code, but the files won’t make business sense in all cases, especially for the newer Toolsets/Instrument Types.  This functionality has been replaced with the ability to run a Operation Services Post-processing script to write out a file with deal details. |
