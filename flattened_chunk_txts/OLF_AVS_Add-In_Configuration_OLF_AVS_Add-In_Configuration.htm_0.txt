 Section heading: Overview.
 Text content: The Script Addin Function Configuration window is where users can configure Script Addins. Note: This functionality is purely for OpenLink internal use only. Users see nothing by default. This functionality requires a license key to enable any/all pieces. This functionality is intended to allow for OpenLink to distribute updated functionality for Scripts without requiring customers to take a full release. This cannot be used for customers to create their own Script Functions. (v90r1 and later) Note: This page is for v90r1 and later. For v82r1 and earlier, see AVS Addin Function Configuration.
