| Configuration Properties | Description |
| --- | --- |
| Column Title | This list contains the titles to display for the columns of data in the grid. This list is user definable. |
| Column Name | This list contains the database names for the columns of data in the grid. This list is for viewing only. |
| Display | De-selecting this check box removes the column from view in the grid. The entry then moves to the bottom of the column properties list where it can be selected again and made visible on the grid. |
| Pinned | When checked, the column(s) are pinned in place along the left side of the grid. This allows the user to scroll the grid left and right and still have the pinned column(s) visible. |
| Sort Order | By numbering the columns in this field, the columns are sorted in that user defined order. This field works together with the Sort Direction field. |
| Sort Dir | This field, along with the Sort Order field, selects which direction (Ascending, Descending, or No Sort) the data should be sorted in. |
| Show Grouped | When checked, the grid displays data grouped by the selected column(s). |
| Group Color | This field allows the user to select a color to distinguish each group within the grid. |
| Conditional Formatting | This field allows the user to create different types of color highlighting, data bars and scales, based on conditions defined by the data in the grid. For example, highlight all trades in red that occurred between January 1, 2011 and February 1, 2011. |
| Aggregate Type | Perform the mathematical operations of Sum, Average, Count, Minimum, and Maximum on the selected column(s). This property also works together with the Grand Total and Sub-Total properties within the General tab. |
| Column Justification | This property sets the horizontal alignment (left, center, right) of the data in the column. Selecting Auto allows the system to select the alignment based on the type of data in the column. For example, dollar amounts are aligned by their decimal points. |
| Auto Size When Shown | If no fixed width is set (Width property) and this property is checked, then the size of the column is based on the size of the data in the column. |
| Width | Sets a fixed width size for the selected column. |
| Column Type | Indicates the content type for the column (Integer, Date Time, String, and Double). This property is for viewing only. |
| Format | The list of formats shown is based on the Column Type. The various formats describe how to display the data in the column. For example, a column type of Date Time has a Format option that can display the time in 24 hour format. |
| Param 1 | Depending on the format chosen, there may be additional configurable parameters. |

| Toggle Formatting | By default, this property is checked for all columns which allows the keyboard shortcut, <Shift> F4 to toggle between formatted output and raw data output. If this property is not checked, then that column will not display raw data when toggled with the keyboard shortcut. |
| Formula | Displays formulas configured for selected columns.This list is for viewing only. |
| Context Menu | Click this field to add an AFE (Adaptive Front End) service to the selected column using theAFE Service Configurationwindow. The configured service displays in the right-click menu list for the selected column. The service may also be configured to display as a right-click menu for the entire data row. |.
