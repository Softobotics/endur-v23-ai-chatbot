 Section heading: Overview.
 Text content: This diagnostic tool has been renamed to ECOM Listen as of v81r1 and up. This screen is used to set up and view communications between OpenLink system Client Workstations and Application Server machines. This screen is used to monitor network traffic generated by the system’s messaging bus. This window consists of the Scope panel , Additional Subjects panel, Filters panel and Message table. The Scope and Additional Subjects panels serve to filter the messages shown in the Message table. The number of messages shown in the table is controlled by the menu item View à Set Message Table Size.  The following Security Privileges are required to access this window:   See System Monitor .
