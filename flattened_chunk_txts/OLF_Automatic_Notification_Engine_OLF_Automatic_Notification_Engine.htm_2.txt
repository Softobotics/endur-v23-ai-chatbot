 Section heading: Starting and Running the ANE from the Services Manager.
 Text content: Once initiated, ANE begins to continuously search the database for all newly entered transactions.  ANE then “broadcasts” these transactions to the entire network.  Each individual user must initiate ANE on their workstation.  Client ANE initiation is done either through the Trading Manger, the Services Manager, or by running an AVS script in the Trading Manager.  Each user can then view the information that is broadcast by the ANE engine. To start ANE: Initialize ANE via the Services Manager.  The user can do this by creating a job that calls a specific task to be run.  This task must be a script that references a fixed query.  An ad-hoc query cannot be run through ASM.  Please reference the ASM documentation for more information on how to create jobs within ASM. .
