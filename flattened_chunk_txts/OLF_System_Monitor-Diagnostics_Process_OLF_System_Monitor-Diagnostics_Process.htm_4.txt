 Section heading: Fields.
 Text content: This window contains the following fields: .
 Table data: 
| Field Item | Description |
| --- | --- |
| Display Name | The name of the process as seen by the end-user. |
| Process Name | The internal system name of the process. |
| Status | The status of the selected process. This field typically shows “Running”. |
| Process ID | The system-designated Process ID (PID). |
| Process Size | The process size, in kilobytes. |
| VM Size | The system virtual memory size for the process. |
| ECOM Sessions | Shows the subscriptions for the messaging tools. The data in this column is of type ‘Table’. Data is accessed by double-clicking the ‘grid’ icon to open the data table. |
| JVM Initialized | An indicator as to whether the process is enabled for Java scripting. |
| JVM Debug Port | The port for which Java scripting debugging can be accessed. |
| Internal Data | System data specific to the selected process. The data in this column is of the type ‘Table’. Data is accessed by double-clicking the ‘grid’ icon to open theInternal System Datatable. Double-click an item within the table to launch a data table specific to the selected item. |.
