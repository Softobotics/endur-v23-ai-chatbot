 Section heading: Accessing this Window.
 Text content: Note : There are multiple 
 ways to access this window; however, only one way is defined because some 
 features can only be accessed via this procedure. 1. From 
 OpenLink Central, right-click anywhere on the header and select Launch 
 Available Services . The Launch Available Services window displays. 2. Type Unit Test Runner in the Filter 
 Service field, highlight Unit Test 
 Runner in the Available Services panel, and then click Launch . The following window 
 displays:  The Unit Test Runner menu contains the 
 following items:  .
