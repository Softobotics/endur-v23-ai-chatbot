 Section heading: Overview.
 Text content: The OLF system accepts date information in several different formats.  The user can enter a specific date in a variety of different configurations, as shown below.  The user can also enter date information using “symbolic dates.”  This is a shorthand in the OLF system for different time periods and different dates.  Dates The system accepts dates in the following formats:  A new Date format was added in 7.0r1 and up: It is called MDY_PERIOD, added under DTS 12217. This has this kind of formatting, based on the Date Local .
