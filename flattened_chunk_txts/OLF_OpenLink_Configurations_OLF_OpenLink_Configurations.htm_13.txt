 Section heading: Adding AFE Desktop Services to OpenLink Central.
 Text content: Before adding the Desktop Service to the console, the desktop must be configured via the OpenLink Desktop Builder or Desktop Wizard 1. Follow the steps above to add a new tab to the console if the desktop service will not be added to an existing console tab. 2. Navigate to the Button Configuration tab and add “OpenLink Desktop” as the Selected Service. The service can be customized with the addition of arguments via the OpenLink Central Config: Service Arguments window. The argument can be the name of a specific desktop or keyword applicable to multiple desktops. If an argument is not supplied, clicking the service button will display a pick list of all available desktops. When a keyword is used as the argument, clicking the service button will display a pick list of applicable desktops. When a specific desktop name is supplied as the argument, clicking the service button will launch the specified desktop. 3. Save the configuration..
