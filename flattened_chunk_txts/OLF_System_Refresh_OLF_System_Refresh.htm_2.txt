 Section heading: Data Caching Mechanisms in Endur/Findur.
 Text content: All versions of the Endur/Findur have some kind of data caching.  In 
	 earlier versions, this cache is called Shared Memory.  In 
	 later versions this technology is called the Cache Engine, which has 
	 several important features that Shared Memory lacked.  It 
	 is more efficient because it only loads data when needed.  Also, 
	 it can add memory dynamically as needed, while Shared Memory was limited 
	 to a predefined amount.  The Cache Engine works like this:.

			 counterparty pick list, are stored in the Cache Engine |
| 8.0 and up | Shared Memory has been removed entirely | All data is stored in the Cache Engine |.
