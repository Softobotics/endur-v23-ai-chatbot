| Field | Description |
| --- | --- |
| Task Name | The name of the task stored in the database. |
| Owner | The user ID the task is assigned to. |
| Category | The category of the task (free form data entry). |
| Group | The name of the security group the task is assigned to.This is a read-only field.  To set this up, you must go the properties window.SeeProperties |
| Last Updated | Lists theUser ID, Date,andTimethe last modification to this task was made. |
| Path to Task | Lists the location where this task is saved. |
| Description | A user-defined text field for entering the description of the task. |
| Param Plugin | The name of the Param Script assigned to this task.  A system pick list is available from which to select existing scripts.AParameterscript is used to prepare information to be passed to a main script.  The tableargtis used to hold data to be passed to a main script.  Parameter scripts can, but are not normally, run without a main script in a Task.If a Task is run in the Trading Manager, then the Parameter Script would be run by the Trading Manager.  If the Task is being run by the Services Manager, then the Parameter Script would be run by the Script Engine. |
| Main Plugin | The name of the Main Plugin assigned to this task.  A system pick list is available from which to select existing plugins.AMainplugin is the main plugin that contains the bulk of the reporting or process-specific code.  A main plugin may be designated to run alone in a Task.If a Task is run in the Trading Manger or Services Manager then the Main Plugin would be run by the Script Engine. |
| Page Viewer Plugin | The name of the Page Viewer plugin assigned to this task.  A system pick list is available from which to select existing plugins.APage Viewerplugin is typically used to set the subscriptions and activate the Page Viewer.If a Task is run in the Trading Manger then the Page Viewer Plugin would be run by the Trading Manager.  If the Task is being run by the Services Manager then the Page Viewer Plugin would be run by the Script Engine. |
| Output Plugin | The name of the Output Plugin assigned to this task .  A system pick list is available from which to select existing plugins.AnOutputplugin is a script that runs locally in the Trading Manager after the main plugin has run.The order in which plugins in a task are run is:First: Page Viewer PluginSecond: Param PluginThird: Main PluginFourth: Output PluginIf a Task is run in the Trading Manger then the Output Plugin would be run by the Trading Manager.  If the Task is being run by the Services Manager then the Output Plugin would be run by the Script Engine. |
| Task Scheduling Upon Completion | This controls task scheduling.Possible ValuesDescriptionStopExecutes the plugin once and stops.Repeat ContinuallySchedules the script to run continuously.  Only the Main Plugin repeats and not the Parameter Script.Warning: Setting plugins to repeat continuously may have severely negative performance implications, and therefore this selection should not be used by anybody without accepting that this mode will cause performance issues.  It will lock up the machine that is running the Task as it will be doing nothing but running the Task continually.  Use the "Repeat Every" option instead, and be sure to set an interval that is longer than the time it takes to run the task.Repeat After Start TimeRepeats the plugin at user-defined intervals.  Enter the interval in the text field, and select the measurement of time from the pop-up list.Every time task repeats, the next run time is set to the last run's start time + repeat_interval.If the repeat interval is less than the actual duration of the task's execution time, the next run time is set to immediately after the current run ends.Notes:1) Only the Main Plugin repeats and not the Parameter Plugin.2) The repeat time is taken after completion of the plugin not the start, i.e., if a task takes 2 min. and the user sets an interval of 3 min., then the task will continue to run 3 minutes after it last started (repeating approximately every 3 min.).3) Setting this value to a time less than is takes to run the Task will cause the same performance issues noted if you choose the "Repeat Continuously" option. Therefore take care to set the repeat time to a time that is longer than it takes for the Task to run (or suffer the consequences in terms of poor performance.)Repeat After End TimeRepeats the plugin
