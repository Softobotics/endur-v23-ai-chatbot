 Section heading: Importing Data.
 Text content: 1. From the General Import/Export tab, select the format of the file to import on the “Format” field. 2. To change the default location of the import file, enter the location of the file to import on the “Filename” field. To browse for the file, click the Browse button. A file browser displays allowing the user to select the location of the file to import. 3. To view the file to import, click the View Import File… button. A spreadsheet/browser displays showing details of the import file. 4. Click the Import button to import data. If import is complete, the message “Import successfully completed.” displays. 5. Click the OK button. The holiday schedule is added to the Holiday Schedules list..
