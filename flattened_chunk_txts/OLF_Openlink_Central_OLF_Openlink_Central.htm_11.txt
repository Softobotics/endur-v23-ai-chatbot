|  | Market Manager | View definitions and data for the following:Prices,Rates,Volatilities, andCorrelations |
|  | Operations Manager | Performs tasks including trade validation, trade settlement, trade confirmation, deal fixing, options exercise, and report generation. |

|  | Admin Manager | Performs multiple tasks including password administration, security privilege and group assignments, as well as static data maintenance. |
|  | Credit Manager | Defines and monitors credit limits through user-defined credit calculations. |
|  | Risk Manager | Defines and monitors risk limits through user-defined risk calculations. |
|  | Accounting Manager | Provides the functionality to generate accounting data from transactions stored within the database. |
|  | System Monitor | Enables the user to monitor various aspects of the system. |
|  | Message Center | Stores messages sent to individual users or personnel groups. Allows users to sign off on stages of a workflow. The in-box icon appears to fill with paper when there are messages. |
|  | Services Manager | Enables users to schedule and monitor workflows, allowing a high degree of automated processes. |
|  | Calendar | Activates theCalendarwindow. Displays different System holiday schedules, date sequences, and roll conventions. |
|  | Crystal Reports | Activates aCrystal Reportswindow which is used to develop and maintain Crystal Tasks. Interfaces between the system and Seagate’s Crystal Reports for generation and viewing of reports generated in Crystal Reports. |
|  | Refresh Static Data | Forces a “refresh” of static and referential data such as security, party groups, settlement instructions, accounts, and currencies.In V7.0 and below: Updates shared memory with static data tables and security privileges. In V8.0 and above: There is no need to push this button for changes made by the user. For changes made by a different user: These can be received by pushing this button or automatically based on the configuration of AB_CE_ACCEPT_EXTERNAL_INVALIDATES. |
|  | System Broadcast | Broadcasts messages to authorized users currently logged into the system. |
|  | System Alert | Opens the systemAlertsscreen. Allows users to view and send alerts. |
|  | Directory Manager | Opens theDirectory Browserwindow. Allows users to view and open directories of scripts, tasks, or queries. |.
