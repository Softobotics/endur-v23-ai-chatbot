 Section heading: Running Services View.
 Text content: The default view of the monitor shows all Connex gateways and services that may or may not take advantage of the Connex grid. Connex grids are configured in the Services Manager module. This view contains the following fields: Right-clicking on a gateway in the tree returns the following menu items..

| Max Run Time | V81r1 and later.The time allotted for a job to run. If a job does not complete in the allotted maximum run time, the job logs as “FAILED. The format used is hours.minutes.  For example, “5” would be five hours, “4.32” would be four hours 32 minutes, and “0.2” would be 2 minutes.  Minutes must be less than 60. Therefore, entering a time 3.67 is not allowed. |
