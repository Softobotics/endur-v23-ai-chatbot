 Section heading: Overview.
 Text content: The Grid Configuration properties module allows the user to customize how data is presented in the grid. The features include the ability to pin columns, color-code individual data, as well as graphing data points and controlling the zooming level on the GUI data grid. The GUI data grid can also be tightly integrated for transaction-based screens. For example, data that is important to the user may want to be highlighted in a particular color, grouped in a particular fashion, or perhaps both in order to make it easier to locate. These types of customizations are available from the Grid Configuration screen. The Configuration screen consists of a General tab for customizing the overall appearance of the grid and a Columns tab for customizing the functionality of each column displayed in the grid..
