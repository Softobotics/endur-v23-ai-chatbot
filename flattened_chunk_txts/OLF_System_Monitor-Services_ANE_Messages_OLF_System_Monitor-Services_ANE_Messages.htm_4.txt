 Table data: 
| Tab | Description |
| --- | --- |
| ANE Msg Subject Types | A pick list of ANE subjects. Selection of a topic(s) results in the related ANE messages showing in the message table. The field defaults to “All”.SeeANE Message Types |
| Auto - Scroll | Selecting this box causes the message screen to automatically scroll when new messages are displayed in the table. This field defaults to on (checked). |
| Time Received | The system date and time the selected message was generated. |
| Message Subject | The topic generating the selected message. |
| Type | The format of the selected message. The available types are table, string or integer. |
| Message Data | The content of the message.Note: If the “Type” is “Table”, double-clicking on the grid icon will display a detail table of the message data. |.
