 Section heading: Editing Scripts/Tasks/Queries/etc. From the View by Directory Tab.
 Text content: To edit scripts, tasks, queries, etc. from the View by Directory tab, 1. From the Directories table, click the folder (i.e., directory) to search. The files of the selected directory displays in the Contents of Directory table. 2. To display only the files of a particular category, select the category in the “File Type” field. This field defaults to “All” so all files contained the selected directory display. 3. Double-click the row to edit in the Contents of Directory table. The applicable screen of the file displays. Note: Another way to open the file is to highlight the row and click the Select button. 4. Edit and save the file..
