|  | Rename Query | Opens theConfigure 
			 Propertieswindow. This window allows the user to 
			 define the ownership values (for example, path, directory, 
			 owner, and group) and permissions for the query that is currently 
			 loaded on screen. |
|  | Delete Query | Deletes the query loaded on screen from 
			 the database. Only the owner of a loaded query may delete 
			 the query (with the exception of administrators and super-users) 
			 unless they have write access. If a user selects this option, 
			 a warning message displays and asks whether the user wishes 
			 to continue. If the user has write access and clicks theOKbutton to confirm the deletion, the loaded query is deleted. 
			 Otherwise, an error message is displayed. |
|  | Compare Queries | Opens the query comparison dialog. The 
			 query comparison dialog box is used to view the differences 
			 between two saved queries. |
|  | Search for Saved

			 queries based on criteria entered in the Query Manager. |
|  | Export Queries | Saves the query that is currently loaded 
			 on screen to a text file. Once the process is complete, the 
			 complete path where the file was saved is displayed. |
|  | Import Queries | Opens a file browser that is used to 
			 navigate to the file that will be imported. Once the process 
			 is complete, details about the import is displayed.Note:To be available, this option 
			 requires Security Privilege 498 “Import Queries.” |
|  | Show Query Security Information | Opens theConfigure
