 Section heading: Importing Objects.
 Text content: To import objects, 1. Load an existing configuration by selecting File à Configure à Load , if desired. 2. Go to the “Files” listbox to add or remove the file from which the data will be imported. To add a file, press the Add button.  A Directory/File dialog box appears for you to select another file. To remove a file from the list, highlight the file and press the Remove button. 3. Go to the “Objects” listbox. Highlight the items to be imported. Only highlighted objects will be imported. To add or remove objects from the list, press the Add Objects button. The Chooser Dialog Box displays. 4. Note: In some cases, the “Objects” listbox and “Add Objects” button are disabled and not displayed when importing files. 5. After selecting the objects and files to import, go to the menu bar and select the “Execute” option. The import process is initiated. As each step in the process occur, the status displays on the Status Bar. Error messages encountered during the process, if any, display on the “Messages” listbox. .
