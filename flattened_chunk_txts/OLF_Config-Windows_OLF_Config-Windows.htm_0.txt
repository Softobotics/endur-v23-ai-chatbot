 Section heading: Overview.
 Text content: The Configuration window allows users to customize the columns in a table or listbox. This is accessible from most screens in the system that contains a listbox, such as Profile, Resets, Fees, Cash Flow, and so forth. It presents users with a complete list of columns for a specific screen, which the user may hide or display.  The user also has the option of assigning aliases to these columns and creating duplicates of these columns. .
