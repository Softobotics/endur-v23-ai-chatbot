 Section heading: Editing Scripts/Tasks/Queries/etc. From the View by Category Tab.
 Text content: To edit scripts, tasks, queries, etc. from the View by Category tab, 1. From the left table, click the category of the file to search. The files of the selected category displays in the File Listing table (i.e., table located at the right side of the screen). 2. Double-click the row to edit in the File Listing table. The applicable screen of the file displays. Note: Another way to open the file is to highlight the row and click the Select button. 3. Edit and save the file. .
