 Section heading: Overview.
 Text content: Current Date Roll is an AFE service that allows you to change the Current Date of the system. It is available from OpenLink Central. You may change the Current Date setting for your session by using the Current Date Roll or by making the change in the Market Manager . This feature requires that you have Security Privilege 100 'Change System Date Menu' enabled. The Current Date is initialized by the Business Date setting defined in the System Date Roll feature in the Operations Manager (if you do not have the Security Privilege 897 ‘Accept Trading Date Updates’ enabled). Your session's Current Date setting is displayed on many system windows and can be used to calculate initial default values for deal settlement date, trade date, start date, and maturity date. In some toolsets the Current Date is used to initialize a date field (e.g. Trade Date) but it can be changed. The OpenLink Configurations window allows users to add the Current Date Roll service to the configuration of OpenLink Central. See Also Market Manager System Date Roll OpenLink Configurations.
