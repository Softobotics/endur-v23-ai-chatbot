 Section heading: Exporting Data.
 Text content: 1. From the General Import/Export tab, select the values of the parameter/s that will be exported. For example, to export historical prices, select the index and the price type that will be exported. 2. Select the format of the file will be saved as in the “Format” field. 3. To change the default location of the export file, enter the path and name of the file where data will be saved in the “Filename” field. To browse for the file, click the Browse button. A file browser displays allowing the user to select the location and name of the export file. 4. Click the Export button to export data. If export is complete, the message “Export successfully completed.” displays. 5. Click the OK button. 6. To view the file to export, click the View Export File… button..
