 Section heading: Fields.
 Text content: This window contains the following fields:.
 Table data: 
| Field | Description |
| --- | --- |
| Current Config | This is a read-only field that contains the currently loaded configuration name. This name represents the configuration file that contains the files and objects to be loaded into the “Files” and “Objects” listboxes.To load other saved configurations, selectFileàConfigureàLoad. |
| Files | This listbox contains the file or files from which data will be imported/exported. If exporting data, the listbox can only contain 1 file, i.e., data are exported to a single file. |
| Objects | This listbox contains the objects (e.g., indexes, volatilities/ correlations, time series data analysis configurations, etc.) to be imported. Highlight the object to import. Unselect objects that will not be imported. You can add and remove items from this listbox through theAdd Objectsbutton.Note: This field is disabled/empty in some functionalities. |
| Status Bar (Above Messages) | This read-only field displays the steps of processing after an import/export is generated, a process that is begun when the “Execute” option is selected off the menu bar. You should receive an “Import/Export Complete” message if the import is successfully completed. |
| Messages | This read-only listbox contains error messages that are generated when objects are imported/exported, a process that is begun when the “Execute” option is selected off the menu bar. |.
