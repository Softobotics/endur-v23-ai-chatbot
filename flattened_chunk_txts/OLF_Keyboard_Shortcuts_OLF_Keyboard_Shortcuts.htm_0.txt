 Section heading: Overview.
 Text content: The following keyboard shortcuts are available in the system:  From the Detailed Deal Input Screens F1 - Displays the symbolic dates on date fields   Other Function Keys Check with the appropriate blotter/module as to whether they can be configured and/or what they are.   In V8.0r1 and up only: There is a system wide configuration variable called AB_TEXT_EDIT_USE_SHORTCUT_KEYS. This flag allows for the configuration of the shortcut keys used in text editors in the system.  There are two possible configurations, one when this is set to TRUE and the other when this is set to FALSE.  FALSE uses hot keys that are consistent with Windows standards.  FALSE is the default value.  TRUE uses an alternate set of hot keys.  In V7.0, the system behaves as if this was set to TRUE.  This affects these windows: 1) AVS Script Editor 2) AVS Script Debugger 3) Adhoc Query 4) Grid Point Definition .
