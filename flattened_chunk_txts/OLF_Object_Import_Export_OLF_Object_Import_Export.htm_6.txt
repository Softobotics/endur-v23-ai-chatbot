 Section heading: Exporting Objects.
 Text content: To export objects, 1. Load an existing configuration by selecting File à Configure à Load , if desired. 2. From the “Files” listbox, add or remove the file from which data will be exported. To remove a file, highlight the file and press the Remove button.  The file is removed from the list. To add a file, press the Add button.  A Directory/File dialog box appears for you to select another file. 3. From the “Objects” listbox, highlight the items to be exported. Only highlighted objects will be exported. To add or remove items from the list, press the Add Objects button. The Chooser Dialog Box displays. 4. After selecting the objects and file to export, go to the menu bar and select the “Execute” option. The export process is initiated. As each step in the process occur, the status displays on the Status Bar. Error messages encountered during the process, if any, display on the “Messages” listbox..
