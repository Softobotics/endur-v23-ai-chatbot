 Text content: This window contains the following fields:.
 Table data: 
| Field | Description |
| --- | --- |
| Name | This is a variable character field of up to 32 characters.  It represents the name of the Task to which privileges are being applied.  If the Task is new and no name assigned yet, data can be entered.  Otherwise, this is a read-only field. |
| Directory/Full Path | Together, these two fields indicate the path and directory in which the task is located.  During a System upgrade, all of the existing tasks in the database are placed in the/Task/Sitedirectory.New tasks are saved to the/Task/Sitedirectory with your user ID as the owner.  Left-click in theDirectoryfield to change the directory of a new task.  A pick list displays from which to chose a new directory. |
| Version | This indicates the number of the current version of the task permission.  The version number is increased each time permission is changed and saved. |
| Owner | This is a pick list field of available user IDs.  The pick list is disabled if this is a new task.  Otherwise, select a user as the owner.  The user ID of the person who creates the task is initially indicated as the owner.  Only someone with the associated permissions, such as the Owner or someone (preferably the database administrator) with the security privilege of either:Directory Node System SuperUser GroupDirectory System Task SuperUser GroupNote:If the original owner of the task is changed, the original owner may lose access rights to the task if they are not part of the group to which the task is assigned. |
| Security Group | This is a pick list field of Security Groups (Security Groups are set up in the Admin Manager).  Choose the group whose members have rights to the selected task and its associated permissions.  A security groupTask DIRNODE Developerswas created and assigned as a default to each of the existing tasks after a database upgrade.Note:The default name of this Security Group (Task DIRNODE Developers) can be changed in the Admin Manager.The default group task assignments can be changed.Only someone with the associated permissions, such as the Owner or someone (preferably the database administrator) with the security privilege of either:Directory Node System SuperUser GroupDirectory System Task SuperUser Group |
| Owner/Group/Public Permissions | These are check box fields that can be toggled on and off.  They grant read, write, and execute privileges to the owner of the task, the security group assigned, and to the general population of users.Note:Execute Permissions are checked by the script engine. |.
