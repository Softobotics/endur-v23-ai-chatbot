 Section heading: Overview.
 Text content: The Table Viewer is a uniform interface with standard user-configurable 
	 features for table viewing. Different modules within the system use 
	 the Table Viewer to display data. Its layout is in the form 
	 of a table, with a number of labeled columns, each representing a 
	 data field, and a number of rows, each representing a data record. 
	 The manner in which information is displayed may be changed through 
	 the Configure View menu 
	 functionality. The Table Viewer grid does not have a defined limit but it is limited by the amount 
	 of memory on a user's machine..
