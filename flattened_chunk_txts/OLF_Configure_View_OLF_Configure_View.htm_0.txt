 Section heading: Overview.
 Text content: The Configure View window is one of the screens that appear in numerous functionalities of the system. This window allows users to configure the table from which this window is accessed. All tables in the system have default settings, i.e., the columns that display by default and how data are presented in the table. From the Configure View window, users can modify the system default settings, i.e., add or remove columns that will be displayed, rename columns, and set up various grouping, sub-totaling, and formatting features. The user has the option to save the configuration for later use.  It can also be set as a default and be applied every time the table is accessed and used. The column titles listed vary and depend on the table that is being configured. .
