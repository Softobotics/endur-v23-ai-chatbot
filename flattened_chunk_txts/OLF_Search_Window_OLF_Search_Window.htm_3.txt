 Text content: This window contains the following buttons: .
 Table data: 
| Button | Description |
| --- | --- |
| Forward | Searches the table from top to bottom. |
| Reverse | Reverses the direction of the search, e.g., from bottom (or from the last matching data) to the top. |
| Col | Searches the table by column. |
| Row | Searches the table by row. |
| Match Case | Toggle to search the data with the specified capitalization. Put a checkmark to locate the data that also has the same capitalization. For example, if “Discount” is the search string and this button is checked, it will not find “discount” or “DISCOUNT.” |
| Search | Executes the search. Once a match is found, press this button again to go to the next match. |.
