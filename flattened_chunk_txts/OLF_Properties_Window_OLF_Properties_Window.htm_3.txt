 Text content: This window contains the following buttons:.
 Table data: 
| Button | Description |
| --- | --- |
| Read | Toggle to allow the owner, security group, or all users to read the file. If checked, the owner, security group, or the public is given the access to read the file. |
| Write | Toggle to allow the owner, security group, or all users to edit the file. If checked, the owner, security group, or the public is given the access to edit the file. |
| Execute | Toggle to allow the owner, security group, or all users to execute or run the file. If checked, the owner, security group, or the public is given the access to run the file. |
| Save | Saves the settings in the window. |
| Cancel | Cancels any modifications to the settings and closes the window. |.
