 Section heading: Defining a New Formula Column.
 Text content: To define a new formula column, 1. Enter the formula in the unlabeled text field by inputting or clicking the desired function, parameters, and operators to insert in the formula. 2. Enter the name, title, and data type of the new column. 3. Click the Apply button.  Important: Only Integers will be used for querying the data. All column values are returned as double and not String Values. The Ad-hoc table viewer should be used to determine integer values for items such as ins type, buy_sell etc.  Formula Examples The following table provides formula usage examples: .
