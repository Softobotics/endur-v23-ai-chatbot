| Seq Num | The order in which the services will run. Number 1 runs first, then number 2, and so on.  If more than one item has the same number, then they are run in random order but before others with a greater number. This is defined in the Operation Services definition. |

| Service Type | The service type of the selected operation service definition. |
| Defn Status | Displays the standing of the selected Operation Service definition. |
| Pre-Process Script | Displays the name of the script that will be run before the trade is processed. |
| Post-Process Script | Displays the name of the script that will be run after the trade is processed. |
| Post-TPM Workflow | The name of the TPM Workflow that is triggered by the selected Operation Service definition. |
