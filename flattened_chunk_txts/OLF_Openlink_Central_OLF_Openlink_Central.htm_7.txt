 Section heading: OpenLink Central Control Panel Sections.
 Text content: The console is comprised of four sections: the Title Bar , the Menu Bar , the System Managers tab(s), and the System Utilities (“ Favorites ”) bar. Each of these sections is described below. · Title Bar – Displays the system code version, the server, the database, and the user logged into the system. · Menu Bar – Displays only if OpenLink Central is in “ Full Mode .” The menu allows the user to set up or modify the configuration of OpenLink Central. If this is hidden, right-click on the Title Bar to display the menu. · System Managers Tab – Displays the OpenLink Tab by default. This tab contains the System Managers. The buttons are active only if the user has access to the respective modules. This may contain other tabs defined by the user. To activate another tab, click the tab or select the tab from the Available Tabs menu. Move the horizontal scroll bar located below the buttons to scroll through the tab. · System Utilities Bar – Contains the System Utilities..
