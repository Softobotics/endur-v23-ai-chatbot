| Show Summations | This is used by the RTPE page viewer.  This check box controls whether or not blanks will show in the header rows of the tree-view instead of summations.  When "Show Summations" is checked, each individual Sum check box in the "Pivot Rows" configuration controls which level of header rows will show sums and which will be blank.See:RTP Page ViewerRTP DefinitionRTP |
| Compress Details | This is used exclusively by RTPE.  Selecting this will cause RTPE details rows to be removed from the pivoted result in the case where the pivot is a grouping.  A group-by pivot can be configured only from the RTPE pivot.  You define pivot columns, pivot rows, but no pivot data.  The pivot columns are those to be displayed along the top.  The pivot rows are those to group on.  The result is simply a sort on the grouped rows, header rows for each sub-group.  When compress details are turned on, the details rows are removed, leaving only the header rows.  Those header rows are transformed into detail rows causing the table to be much smaller to send over the network.See:RTP Page ViewerRTP DefinitionRTP |
| Show Tree View | This causes the RTPE page viewer to display the resulting pivot table as a flat view without the tree view expand and collapse column and icons. |
