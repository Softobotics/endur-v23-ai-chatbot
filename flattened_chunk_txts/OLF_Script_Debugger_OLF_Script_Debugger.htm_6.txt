 Section heading: <sdbg> Shell.
 Text content: The shell "terminal" is the lower text area in the sdbg window. Type help at a <sdbg> prompt.  A list of sdbg commands, including print, breakpoint, continue, step, finish, skip, set, and help displays.  Note: Print [variable] should be print [expression].  An expression can be of any form acceptable in a script, such as x * (y+3), 10*growth(rate, dcf) , and so on.  Abbreviation: When a command is typed, its prefix can be used as long as this prefix does not confuse another command above it in this list e.g., use 's' for step, 'sk' for 'skip', and 'se' for set.  Command history is supported.  You can either move the cursor back to a previous command and hit RETURN/ENTER , or, use M-P, M-N to navigate along command history..
