 Section heading: Adding a New Tab in OpenLink Central.
 Text content: To add a new tab to the OpenLink Central Console : 1. Select Tab Configuration . 2. Click the Add Tab button. The Add New Tab Page window displays. 3. Enter the name and text for the tool tip in the appropriate fields. 4. Click the OK button. The tab is added to the “Available Tabs” list. 5. Click the OK button to accept the changes and close the window..
