 Section heading: Overview.
 Text content: The G eneral Import/Export window is used to import/export a variety of system data/definitions from/to .CSV or XML formats. This window is used for import/export in many areas of the system. Examples are listed below. This window allows the user to invoke general importing and exporting functions, as well as setting up the definition to be used. It may or may not contain different parameters that may be needed to correctly import/export data. While window titles may vary, the design and functionality are the same. This window is used to import/export the following: · Historical Prices/Hourly Historical Prices – Uses Index Name and Price Type as parameters · Curve Adjustment – Uses the Adjustment Definition Name as parameter · Static Data – The static data being imported/ exported is used as parameter · Time Zones – Uses TimeZone Label as parameter · Products – Uses Product Type and Name as parameters · Bond Futures Conversion Factors – Uses the Instrument Number as parameters · Settlement Desktop Definition – Refer to Settlement Desktop for the description of the parameters · Market Volatility Definitions - v10.0r2 and up..
