| Configuration Properties | Description |
| --- | --- |
| View |
| View Type | The default view for the grid isGridView, where data is displayed in columns with headings along the top of the input table; for this example, it would be displayed in the diff table window. Alternatively, by selectingPropertyView, the columns are shown as rows with headings listed down the left side of the table. |
| Show Zoom Control | If checked, the zoom control (used to adjust the font size of the data in the grid) is displayed in the lower right hand corner of the grid. |
| Show Quick Configure | When checked, theQuick Configureicon () is displayed in the upper left corner of the grid. TheQuick Configuremenu provides easy access to some of the more common visual aspects of the grid (for example, grouping, zooming, maximizing, and charting). |
| Show Saved Configurations | If selectable and checked, this option allows the user to select from a list of saved configurations right below the grid. |
| Grouping |
| Show Grouping Control | When checked, the grouping control area is displayed above the grid. The user drags the desired column headings to the grouping control area and the grid is reformatted into groups. |
| Show Groups As Tree | This option is used along with the Show Grouping Control option to refine the grouped data into a treeview structure. In this mode, groups can be individually expanded and collapsed to make the grid more readable. |
| Expand Groups Initially | When selected, the items in the tree are automatically expanded on loading the data table when grouping is selected. |
| To Level | This field is used to define the level to which the tree view will automatically be expanded. |
| Group Caption Style | By default (Valueoption), the data contained under the column heading dragged into the grouping control area is used as the name for each group.If the optionValue (Count)is selected, then the total number of objects contained in the group is displayed next to the group name.If the optionCaption: Value (Count)is selected, then the column heading title, group name, and number of objects are displayed as the title of the group. |
| Hide Grouped Columns | When selected, the columns on which the grouping is based will not be shown in the data table.When this field is not selected, the column on which the grouping is based will display in the data table with a triangle symbol indicating that it is the basis of the grouping. |
| Appearance |
| Use Alternate Row Theme | Formats rows with alternating color. By default, each row alternates between white and green; however, the background and foreground colors can be modified by selecting buttonsBGandFGrespectively. ASampletable cell is shown depicting the colors used. |
| Show Conditional Formatting | When checked, and if conditional formatting colors have been configured, then they are shown in the grid. However, if both the Show Conditional Formatting and the Use Alternate Row Theme options are checked, then the Use Alternate Row Theme will take priority. |
| Grid View Settings |
| Row Header Width | Defines the width of the first cell in each row. This option is only available in the Grid View. |
| Column Header Position | Displays the Header row at the Top of the Grid or at the Top of Each Group, if grouping is used. This option is only available in the Grid View. |
| Property View Settings |
| Show Column Headers | When checked, displays a heading row at the top of the grid. This option is only available in the Property View. |
| Data to use as Header Text | If Show Column Headers is checked, this field is used to select the data type to display in the header row. This option is only available in the Property View. |
| Row Header Position | Displays the Header row at the Top of the Grid or at the Top of Each Group, if grouping is used. This option is only available in the Property View. |
| Totals |
| Show Grand Total | Based on which column(s) have an Aggregate Type set (Sum, Average, Count, Minimum, Maximum), checking this option displays a grand total for the column(s) as the last row of the grid. |
| Sub-Total Location | If grouping is used and an Aggregate Type set is selected for one or more columns, then a sub-total can be displayed at either the Top of the Group, Bottom of the Group, or the Top and Bottom of the Group. |.
