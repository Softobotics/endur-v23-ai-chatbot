 Section heading: Setting up The Calendar.
 Text content: 1. Move the cursor to the Date Picker field. The default value for this field is the current system month and year. S elect a month and year by using the left (back) and right (forward) arrows in the scroll bar or enter the desired month and year into the field and Click Enter . 2. Click the Holiday field and select a holiday schedule from the popup list.  Click OK . 3. Click the Date Sequence field and select a date sequence from the popup list.  Click OK . 4. Click the Roll Convention field and select a roll convention from the popup list. Click OK . 5. Check Show Days from Today to display financial business days and actual days between the selected date and the current date in the calendar (This will only be available if the AB_CALENDAR_SHOW_DAYS_FROM_TODAY environment variable described above is set to True). 6. Check Show Julian Dates to display Julian dates in the calendar. (This will only be available if the AB_CALENDAR_SHOW_JULIAN_DATES environment variable described above is set to True). 7. Check Jump to activate calendar jumps to supplied Julian Date and Date String dates. (This will only be available if the AB_CALENDAR_SHOW_JULIAN_DATES environment variable described above is set to True). 8. Examine the lower panel of the Calendar window. The criteria specified in the top panel displays the appropriate holidays, date sequences and options for the selected month in the lower panel..
