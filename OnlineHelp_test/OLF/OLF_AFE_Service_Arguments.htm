OpenLink Central Config Service Arguments

Overview

The OpenLink Central Config: Service Arguments window is used to pass service arguments to OpenLink Services. Service Arguments facilitate the:

·         Association of an OpenLink Central Service with a specific service definition using OpenLink Central Configurations (e.g., OpenLink Desktop with “My Desktop”)

·         Configuration of an AFE (Adaptive Front End) Service for OpenLink Central as a process to open screens directly

·         Employment of AFE (Adaptive Front-End) Desktop Services filtered pick lists for OpenLink Central buttons

Accessing This Window/Screen

To access this window:

1.    Launch OpenLink Central if it is not already in use.

2.    Select OpenLink CentralàEdit Configuration from the menu icon or menu bar to launch the OpenLink Central Configuration window.

3.    Select the Button Configuration Tab.

4.    Select a service (NOTE: Not all services have arguments).

5.    Use the “Service Selection” pick list in the Button Properties frame to select the type of string (screen_name, keywords, etc.).

6.    Click the Args button.

Fields

This window contains the following fields:

Field

Description

Name

Displays the name of the argument.

Type

Displays the type of service argument.

Value

The service or keyword that should be used to launch a service or a list of available services.

In v9.1r2 and later, when a service requires arguments that have a set of known values, the user is presented with a pick list of valid items to select rather than having to manually type in values (as in the Static Data example shown in the images).

Adding an Argument to a Service

To add an argument to a service:

1.    Click the Args button in the OpenLink Central Configuration window.

2.    Enter the argument value in the OpenLink Central Config: Service Arguments window and click OK.

For example, if a “named” desktop is being added to the OpenLink Central Console, enter the name (String screen_name) of the desktop in this screen. A desktop saved as “Back Office”, is tagged as “Back Office” in this screen, to be launched when using the button.

NOTE:   When services with a known set of values are selected, the “Value” field will present a pick list for easier argument selection.
