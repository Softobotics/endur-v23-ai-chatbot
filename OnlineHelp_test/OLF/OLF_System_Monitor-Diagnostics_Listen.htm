System Monitor - Diagnostics - RV Listen

Overview

This diagnostic tool has been renamed to ECOM Listen as of v81r1 and up.

This screen is used to set up and view communications between OpenLink system Client Workstations and Application Server machines. This screen is used to monitor network traffic generated by the system’s messaging bus.

This window consists of the Scope panel, Additional Subjects panel, Filters panel and Message table. The Scope and Additional Subjects panels serve to filter the messages shown in the Message table. The number of messages shown in the table is controlled by the menu item View à Set Message Table Size.

Accessing This Window/Screen

To access this window:

  1. Start the OpenLink System.
  2. From OpenLink Central, click the System Monitor icon
  3. Select the Diagnostics tab.
  4. Select the RV Listen or ECOM Listen sub-tab (depends upon the system version).

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

 

Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.

 

Buttons

This window contains the same toolbar buttons as the System Monitor. This tab includes the following buttons:

Button

Description

Select this button to display messages in the table based upon the selected “Scope” and “Subject(s)”. Messages will not be shown if the button is not selected.

Cancels the request for system messages to be shown in the table.

Removes all message data from the table.

 

Fields

This window contains the following fields:

Field Item

Description

Scope

DB Server

Select this to monitor external messages generated by the selected database.

Local

Select this to monitor internal messages generated by the user’s System session.

Remote Local

Select this to monitor messages generated by another user’s System session.

Additional Subjects

Subject

Three free-text fields that serve as filters on the messages shown in the table.

Filters

NOTIFY Msg Types

A pick list of the types of notification messages that may be monitored.

RPC Msg Types

A pick list of the types of request/reply messages that may be monitored.

 

Auto-Scroll

Selecting this box causes the message screen to automatically scroll when new messages are displayed in the table. This field defaults to on (checked).

Count

The number of messages received since subscribing.

Time Received

The system date and time the selected message was generated.

Message Subject

The topic generating the selected message.

Type

The message data type.

Message Data

The content of the message.

Note: If the “Type” is “Table”, double-clicking on the grid icon will display a detail table of the message data.
