Single Icon Import

This window allows user icons to be imported into the system one icon at a time. User icons imported into the system can be used by the Data Explorer.

 

Note: For information on importing more than one user icon at a time, refer to Bulk Icon Import.

 

Accessing This Window/Screen

To access thiswindow:

1.    Start OpenLink Central.

2.    Select Launch Available Services from the menu.

3.    In the Filter Service field, enter the service name “Single Icon Importer.”

4.    Select the service from the Available Services panel and click Launch.

The following window displays:

Fields

This window contains the following fields:

Field

Description

Icon Name

Displays the name of the icon file to be imported. Used in conjunction with the Browse button.

 

Preview Panel

This panel displays the icon before it is imported in the system. The icon is shown in three sizes:

·         Native Image Size: The actual size of the icon being imported

·         Small: 16x16 pixels

·         Large: 32x32 pixels

 

Buttons

This window contains the following buttons:

Button

Description

Opens a standard file selection window for choosing the icon file to be imported.

Opens a Properties window in which the properties and permissions for the icon can be set. Clicking the Save button in this window imports the icon file into the system.

Closes the window.

 

Importing an Icon File

To import a single user icon file:

  1. Click the Browse button and select the icon file to be imported.

The name of the selected file appears in the Icon Name field. The icon also appears in the Preview panel.

  1. Click Import.
  2. In the Properties window, select the applicable properties for the icon file.
  3. Click Save.
