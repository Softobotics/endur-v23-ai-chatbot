Crystal Report Viewer

Overview

After a Crystal Report has been designed and executed, the results can be saved within the database.  This function allows the user to view previously saved Crystal Report results.

Crystal Reports can be accessed from the Crystal Reports window and directly from the Trading Manager.

See Crystal Reports

 

Accessing This Window/Screen

  1. Select the Crystal Report icon  from the system Control Panel. The Crystal Reports – Master window displays.
  2. Select File à Open Viewer
     OR
     Click the Open Viewer icon .
  3. The following window displays:

Another way to access this window:

  • Open the Trading Manager. Select View à Crystal Report Viewer from the menu.

 

Menu Items

This window contains the following menu items:

Menu

Item

Description

File

Open Report

Allows the user to select a report previously saved in crystal report format (.rpt). Displays the Select a Saved Report pop-up window to allow selection of report.

 

Close All Report Windows

Cancels and closes all open Crystal Report Viewer windows.

 

Print Screen

Prints the current window.

 

Exit

Exits from the current window.

Help

Help

Displays the system Help files.

 

Buttons

This window contains the following buttons:

Button

Description

Performs the same function as File à Print Screen.

Displays the current report in a viewing window. 

Prints the current report to the default printer. 

Exports the current report to any of the formats supported by Crystal.  Supported formats include HTML, ODBC, Word, Excel, Lotus Notes, text files, and e-mail.
Browse

Displays the Select a Saved Report pop-up window.  Allows the user to browse through directories to select report to view. 

 

Fields

This window contains the following fields:

Report Information Panel

Field

Description

Report Name

Specifies the full path and file name of a saved Crystal report.  There are two ways to load a desired report:

  • Use the Browse button to select a saved report
  • Use File à Open Report to select a saved report

This is a display only field.

Report Title

Displays the text that displays in the title bar of the Report Viewer window when a view of the selected report is generated. 

 

Summary Information Panel

Field

Description

Date/Time

Displays the date and time the selected report was last generated.  This is a display only field.
Author

The user ID of the person who generated the report.  This is a display only field.

Subject

This is a display only text field that contains an explanation of the subject of the report.

Keywords

This is a display only text field that contains keywords saved with the report.
Comments

This is a display only field that contains comments the author entered when the report was saved.
