Pivot Table

Overview

The Pivot Table Setup window is used to create an interactive report that summarizes and analyzes data from existing tables. The pivot table is defined by the pivot columns, pivot rows, and pivot data attributes that are selected. Pivot rows are used for grouping (sorting) the data; the pivot columns are used to generate unique sets of pivot columns in the resulting pivot view; and the pivot data is the attribute used to aggregate data into the actual pivot view cells from the original table. This window is accessed from the RTPE (Real Time Position Engine) Page Configuration window and various functionalities that employ the Table Viewer.

Warning: Users can only save pivot table configurations as part of the set up for RTPE (Real Time Position Engine). This menu item allows you to configure a pivot table for one time use only.

Accessing This Window/Screen

For illustration purposes, the following is an example of how it is accessed:

1.    Start the Trading Manager.

2.    Select Misc à Registered Pricing Models. The Registered Pricing Models window displays. This window is an example of a Table Viewer.

Compress Details

This is used exclusively by RTPE.  Selecting this will cause RTPE details rows to be removed from the pivoted result in the case where the pivot is a grouping.  A group-by pivot can be configured only from the RTPE pivot.  You define pivot columns, pivot rows, but no pivot data.  The pivot columns are those to be displayed along the top.  The pivot rows are those to group on.  The result is simply a sort on the grouped rows, header rows for each sub-group.  When compress details are turned on, the details rows are removed, leaving only the header rows.  Those header rows are transformed into detail rows causing the table to be much smaller to send over the network.

Creating a Pivot Table

To create a pivot table,

a)    Select from the “Pivot Table” listing the fields that will represent the column, row, and data of the pivot table. To select the field, highlight the field/s in the “Pivot Table” listing and click the appropriate “Add” button to move them to the Column, Row, and Data listing.

b)    Define additional settings for the pivot table, e.g., sum, colors, show summation, etc.

c)    Click the Pivot Table button. The pivot table displays.
