Alerts

Overview

This window is where you can see and send Alerts.

 

Accessing This Window/Screen

To access this window:

  1. From the Main Menu, click the Alerts   button.
  2. The following window displays:

 

 

Menu Items

This window contains the following dropdown menu items:

Menu

Item

Description

File

Clear Log

Deletes the contents of the Alert Log.

 

Print Screen

Prints the current screen.

 

Clear Query

Clears all the currently loaded settings in the Query Panel and resets them to the defaults.

 

 

Load Query

 

Reloads the settings from the last time they were saved to the default file.

 

 

 

Save Current Saved Setup File As Default

Saves the current settings to the default file, so they can be reloaded the next time the user opens up the workbench.  When saving settings, the user can specify that the settings be loaded automatically when the Alert screen is loaded.

Alert Administration

Create Functional Groups

Helps you create the name of the Functional Groups.

 

 

 

Personnel Maintenance

 

 

 

 

 

 

Opens the Personnel Maintenance window that allows users to create or edit all the personnel records entered in to the system.  This includes records for external and internal System users.  Once personnel records have been created, the user can add them to business units and legal entities later.  The user also has the option of assigning personnel to portfolios, security groups, secured tasks, secured indexes and other configuration attributes.

 

 

 

Create Alert Categories

Opens the Alert Categories Table. Helps you to create the name of the Alert Categories. The user can type up to 32 characters in length.

 

 

 

Create Alert Receipt Status

Opens the Alert Receipt Status Table. Helps you to create the name of the Alert Categories. The user can type up to 32 characters in length.

 

Refresh Database Status

Allows user to update the changes made in the static data such as Functional Groups, Alert Categories and Alert Receipt Status tables.

View

Drill Down

Helps you to drill down and find more details for each Alert.

 

Alert History > Alert Receipt History

Allows viewing the data in the window to reflect any changes entered through the Alert for the individual user.

 

 

Alert History > Alert History

Allows viewing the data in the window to reflect any changes entered through the Alert for the All users.

Configurations

Configure Message Log

Opens the Configure View table. Users can set up various grouping, sub-totaling and formatting features as a configuration.  The configuration can be saved for later use. 

Help

Help

Displays the system Help files.

An ANE-based feature that flashes to notify users that the selected Alert is not the most current data set.  The icon blinks in one of the following circumstances, notifying you that your Alert data is not the most current available:

  • Another user has modified the data set since the time you originally run the data set
  • You are using a selected Personal index

New Alert

Opens the New Alert Window.

Select Status

Helps to assign a new status to the Alert. Following options are available:

  • Closed
  • Open
  • Read
  • Reassign
  • Unread

To update the status on the Alert after selecting the appropriate status, the user needs to click on Change Status button.

 

Change Status

Helps to update the status of an Alert based on the assigned status selected in the Select Status Field.

Close for All

Closes the Alert for all the users

Current Date

Displays the current date of the system. The current date is initialized by the Business Date setting defined in the System Date Roll feature in the Operations Manager (if you do not have the Accept Trading Date Updates security privilege enabled). 

You may change the Current Date setting for your session only in the Market Manager or using the Current Date Roll AFE Service from OpenLink Central. Any User Can Close

If the value in this field is set to “1” then anyone can close this Alert. “Anyone Can Close” can be activated in the new Alert window when assigning a new Alert by clicking on the “Allow any user to close all” field.

Receiver Must Close

If the value in this field is “0” then any user can close this Alert. If the value in this field is “1”, this Alert can only be closed by the user assigned to the Alert.

Version Number

This is not an editable field. Every time a change to the record is made and saved, the version number is incremented by one.
