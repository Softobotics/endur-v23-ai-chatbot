OpenLink Central Configuration

Overview

The OpenLink Central Configuration window allows users to add, remove and configure tabs and buttons (services) available in the OpenLink Central Console. Existing tabs may be deleted or renamed and new tabs may be created. AFE (Adaptive Front-End) Desktop services may also be added and removed using this window.

The View Configuration tab was added in V12.1 and above. This tab is used to configure the appearance of the OpenLink Central Console when it is accessed from an OpenLink Central Sidebar. Selections made in this tab do not impact the configuration of the console.

Adding a New Tab in OpenLink Central

To add a new tab to the OpenLink Central Console:

1.    Select Tab Configuration.

2.    Click the Add Tab button. The Add New Tab Page window displays.

3.    Enter the name and text for the tool tip in the appropriate fields.

4.    Click the OK button. The tab is added to the “Available Tabs” list.

5.    Click the OK button to accept the changes and close the window.

Removing an Existing Tab in OpenLink Central

To remove a tab from the OpenLink Central Console:

1.    Select Tab Configuration.

2.    Highlight the tab to delete in the “Available Tabs” list.

3.    Click the Delete Tab button. The tab is removed from the list.

4.    Click the OK button to accept the changes and close the window.

Adding a Service to OpenLink Central

To add a service that can be launched from an OpenLink Central Console tab:

1.    Select the Button Configuration tab.

2.    Select the tab where the service will be added in the “Tab Name” field.

3.    Highlight the service that will be selected in the “Available Services” list, more than one service may be selected. The “Available Services” list may be reduced by selecting a Group Filter or entering a string in the search field.

4.    Click the right-pointing arrow button. The service displays in the “Selected Services” list.

5.    To reorder the “Selected Service” list, highlight the service to move and click the down arrow or up arrow button.

6.    To enter a service argument, click the Args button. The OpenLink Central Config: Service Arguments window displays. Enter the argument and click the OK button. For example, if you are adding your “named” desktop in OpenLink Central, enter the name of the desktop in this screen. If your desktop was saved as “My Desktop”, enter “My Desktop” in this screen.

7.    Enter the button caption and tool tip in the “Button Caption” and “Tool Tip Text” fields, respectively.

8.    Select the icon for the service from the “Button Icon” field. The selected icon displays in the Icon Preview panel.

9.    Click the OK button. The icon is now added to the selected OpenLink Central tab. To launch the service, click the icon.

Adding AFE Desktop Services to OpenLink Central

Before adding the Desktop Service to the console, the desktop must be configured via the OpenLink Desktop Builder or Desktop Wizard

1.    Follow the steps above to add a new tab to the console if the desktop service will not be added to an existing console tab.

2.    Navigate to the Button Configuration tab and add “OpenLink Desktop” as the Selected Service. The service can be customized with the addition of arguments via the OpenLink Central Config: Service Arguments window. The argument can be the name of a specific desktop or keyword applicable to multiple desktops.

If an argument is not supplied, clicking the service button will display a pick list of all available desktops.

When a keyword is used as the argument, clicking the service button will display a pick list of applicable desktops.

When a specific desktop name is supplied as the argument, clicking the service button will launch the specified desktop.

3.    Save the configuration.
