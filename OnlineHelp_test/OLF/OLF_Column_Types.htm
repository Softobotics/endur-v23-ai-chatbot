Column Types

Overview

This window is accessed through the Configure View window.  It shows the different columns in the table and describes the type of data contained therein.  It also allows the user to view the tables that make up the different columns.

 

Accessing This Window/Screen

To display this window:

  1. Open the Configure View window.
  2. Select View à All Formats.
  3. The following window displays:

 

 

Menu Items

This window contains the same menu items as the Table Viewer window.

 

Buttons

This window contains the following buttons:

Button

Description

Prints the current window.

 

Fields

This window contains the following fields:

Field

Description

int values

This is a sequential number generated by the system to accompany each column listing.

enums

Column Type

formats

Displays the format types for each Column Types.  To see the format types, double-click on the grid icon in the appropriate row.

 

Viewing Tables From The Column Types Window

The Column Types window allows users to view the actual tables whose names are displayed in each column by double clicking in the “grid” icon in the “Formats” column to the left of each row listing.
