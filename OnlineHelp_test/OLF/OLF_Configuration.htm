Grid Configuration Window

Overview

The Grid Configuration properties module allows the user to customize how data is presented in the grid. The features include the ability to pin columns, color-code individual data, as well as graphing data points and controlling the zooming level on the GUI data grid. The GUI data grid can also be tightly integrated for transaction-based screens. For example, data that is important to the user may want to be highlighted in a particular color, grouped in a particular fashion, or perhaps both in order to make it easier to locate. These types of customizations are available from the Grid Configuration screen.

The Configuration screen consists of a General tab for customizing the overall appearance of the grid and a Columns tab for customizing the functionality of each column displayed in the grid.

Accessing the Configuration Window

This window may be accessed through multiple modules. For this example, the Market Manager is used.

To access this window:

1.    Launch the Market Manager.

2.    Select MiscàAuthorize Indexes, or MiscàAuthorize Volatilities, or MiscàCorrelations. The Two Step Validation window displays.

3.    Click the View Differences button. The diff table window displays.

4.    Select ConfigureàConfigure from the main menu.

The following window displays.

Menu Items

This window has the same menu items as the Table Viewer.

General Tab Fields

Configuration Properties

Description

View

View Type

The default view for the grid is Grid View, where data is displayed in columns with headings along the top of the input table; for this example, it would be displayed in the diff table window. Alternatively, by selecting Property View, the columns are shown as rows with headings listed down the left side of the table.

Show Zoom Control

If checked, the zoom control (used to adjust the font size of the data in the grid) is displayed in the lower right hand corner of the grid.

Show Quick Configure

When checked, the Quick Configure icon () is displayed in the upper left corner of the grid. The Quick Configure menu provides easy access to some of the more common visual aspects of the grid (for example, grouping, zooming, maximizing, and charting).

Show Saved Configurations

If selectable and checked, this option allows the user to select from a list of saved configurations right below the grid.

Grouping

Show Grouping Control

When checked, the grouping control area is displayed above the grid. The user drags the desired column headings to the grouping control area and the grid is reformatted into groups.

Show Groups As Tree

This option is used along with the Show Grouping Control option to refine the grouped data into a treeview structure. In this mode, groups can be individually expanded and collapsed to make the grid more readable.

Expand Groups Initially

When selected, the items in the tree are automatically expanded on loading the data table when grouping is selected.

To Level

This field is used to define the level to which the tree view will automatically be expanded.

Group Caption Style

By default (Value option), the data contained under the column heading dragged into the grouping control area is used as the name for each group.

If the option Value (Count) is selected, then the total number of objects contained in the group is displayed next to the group name.

If the option Caption: Value (Count) is selected, then the column heading title, group name, and number of objects are displayed as the title of the group.

Hide Grouped Columns

When selected, the columns on which the grouping is based will not be shown in the data table.

When this field is not selected, the column on which the grouping is based will display in the data table with a triangle symbol indicating that it is the basis of the grouping.

Appearance

Use Alternate Row Theme

Formats rows with alternating color. By default, each row alternates between white and green; however, the background and foreground colors can be modified by selecting buttons BG and FG respectively. A Sample table cell is shown depicting the colors used.

Show Conditional Formatting

When checked, and if conditional formatting colors have been configured, then they are shown in the grid. However, if both the Show Conditional Formatting and the Use Alternate Row Theme options are checked, then the Use Alternate Row Theme will take priority.

Grid View Settings

Row Header Width

Defines the width of the first cell in each row. This option is only available in the Grid View.

Column Header Position

Displays the Header row at the Top of the Grid or at the Top of Each Group, if grouping is used. This option is only available in the Grid View.

Property View Settings

Show Column Headers

When checked, displays a heading row at the top of the grid. This option is only available in the Property View.

Data to use as Header Text

If Show Column Headers is checked, this field is used to select the data type to display in the header row. This option is only available in the Property View.

Row Header Position

Displays the Header row at the Top of the Grid or at the Top of Each Group, if grouping is used. This option is only available in the Property View.

Totals

Show Grand Total

Based on which column(s) have an Aggregate Type set (Sum, Average, Count, Minimum, Maximum), checking this option displays a grand total for the column(s) as the last row of the grid.

Sub-Total Location

If grouping is used and an Aggregate Type set is selected for one or more columns, then a sub-total can be displayed at either the Top of the Group, Bottom of the Group, or the Top and Bottom of the Group.

Columns Tab Fields

Configuration Properties

Description

Column Title

This list contains the titles to display for the columns of data in the grid. This list is user definable.

Column Name

This list contains the database names for the columns of data in the grid. This list is for viewing only.

Display

De-selecting this check box removes the column from view in the grid. The entry then moves to the bottom of the column properties list where it can be selected again and made visible on the grid.

Pinned

When checked, the column(s) are pinned in place along the left side of the grid. This allows the user to scroll the grid left and right and still have the pinned column(s) visible.

Sort Order

By numbering the columns in this field, the columns are sorted in that user defined order. This field works together with the Sort Direction field.

Sort Dir

This field, along with the Sort Order field, selects which direction (Ascending, Descending, or No Sort) the data should be sorted in.

Show Grouped

When checked, the grid displays data grouped by the selected column(s).

Group Color

This field allows the user to select a color to distinguish each group within the grid.

Conditional Formatting

This field allows the user to create different types of color highlighting, data bars and scales, based on conditions defined by the data in the grid. For example, highlight all trades in red that occurred between January 1, 2011 and February 1, 2011.

Aggregate Type

Perform the mathematical operations of Sum, Average, Count, Minimum, and Maximum on the selected column(s). This property also works together with the Grand Total and Sub-Total properties within the General tab.

Column Justification

This property sets the horizontal alignment (left, center, right) of the data in the column. Selecting Auto allows the system to select the alignment based on the type of data in the column. For example, dollar amounts are aligned by their decimal points.

Auto Size When Shown

If no fixed width is set (Width property) and this property is checked, then the size of the column is based on the size of the data in the column.

Width

Sets a fixed width size for the selected column.

Column Type

Indicates the content type for the column (Integer, Date Time, String, and Double). This property is for viewing only.

Format

The list of formats shown is based on the Column Type. The various formats describe how to display the data in the column. For example, a column type of Date Time has a Format option that can display the time in 24 hour format.

Toggle Formatting

By default, this property is checked for all columns which allows the keyboard shortcut, <Shift> F4 to toggle between formatted output and raw data output. If this property is not checked, then that column will not display raw data when toggled with the keyboard shortcut.

Formula

Displays formulas configured for selected columns. This list is for viewing only.

Context Menu

Click this field to add an AFE (Adaptive Front End) service to the selected column using the AFE Service Configuration window. The configured service displays in the right-click menu list for the selected column. The service may also be configured to display as a right-click menu for the entire data row.
