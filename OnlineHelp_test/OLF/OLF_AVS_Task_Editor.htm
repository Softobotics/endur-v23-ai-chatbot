Task Editor

Overview

To run a plugin, a task must first be created.  The task schedules plugins to run at specific times or specific intervals.  Using the Components feature, specific plugins are assigned as components of a task.  This is the blueprint and tells the task what type and what plugin name to run.  Tasks can be defined within the Trading, Credit, or Risk Managers or through the Script button of the Operation Manager. Scripts can be imported (through Operations Manager à Script) before assigning them to tasks.

Note: This page is for v90r1 and later. For v82r1 and earlier, see AVS Task Editor.

Note: Plugins were formerly known as Scripts and as AVS Scripts.

A user-defined text field for entering the description of the task.

Param Plugin

The name of the Param Script assigned to this task.  A system pick list is available from which to select existing scripts.

 

A Parameter script is used to prepare information to be passed to a main script.  The table argt is used to hold data to be passed to a main script.  Parameter scripts can, but are not normally, run without a main script in a Task.

 

If a Task is run in the Trading Manager, then the Parameter Script would be run by the Trading Manager.  If the Task is being run by the Services Manager, then the Parameter Script would be run by the Script Engine.

Main Plugin

The name of the Main Plugin assigned to this task.  A system pick list is available from which to select existing plugins.

 

A Main plugin is the main plugin that contains the bulk of the reporting or process-specific code.  A main plugin may be designated to run alone in a Task.

 

If a Task is run in the Trading Manger or Services Manager then the Main Plugin would be run by the Script Engine.

Page Viewer Plugin

The name of the Page Viewer plugin assigned to this task.  A system pick list is available from which to select existing plugins.

 

A Page Viewer plugin is typically used to set the subscriptions and activate the Page Viewer.

 

If a Task is run in the Trading Manger then the Page Viewer Plugin would be run by the Trading Manager.  If the Task is being run by the Services Manager then the Page Viewer Plugin would be run by the Script Engine.

Output Plugin

The name of the Output Plugin assigned to this task .  A system pick list is available from which to select existing plugins.

 

An Output plugin is a script that runs locally in the Trading Manager after the main plugin has run. 

The order in which plugins in a task are run is:

First: Page Viewer Plugin

Second: Param Plugin

Third: Main Plugin

Fourth: Output Plugin

 

If a Task is run in the Trading Manger then the Output Plugin would be run by the Trading Manager.  If the Task is being run by the Services Manager then the Output Plugin would be run by the Script Engine.

Task Scheduling Upon Completion

This controls task scheduling.

Possible Values

Description
Stop

Executes the plugin once and stops.

Repeat Continually

Schedules the script to run continuously.  Only the Main Plugin repeats and not the Parameter Script.

Warning: Setting plugins to repeat continuously may have severely negative performance implications, and therefore this selection should not be used by anybody without accepting that this mode will cause performance issues.  It will lock up the machine that is running the Task as it will be doing nothing but running the Task continually.  Use the "Repeat Every" option instead, and be sure to set an interval that is longer than the time it takes to run the task.

Repeat After Start Time

Repeats the plugin at user-defined intervals.  Enter the interval in the text field, and select the measurement of time from the pop-up list. 

Every time task repeats, the next run time is set to the last run's start time + repeat_interval.

If the repeat interval is less than the actual duration of the task's execution time, the next run time is set to immediately after the current run ends.

Notes:

1) Only the Main Plugin repeats and not the Parameter Plugin.

2) The repeat time is taken after completion of the plugin not the start, i.e., if a task takes 2 min. and the user sets an interval of 3 min., then the task will continue to run 3 minutes after it last started (repeating approximately every 3 min.).

3) Setting this value to a time less than is takes to run the Task will cause the same performance issues noted if you choose the "Repeat Continuously" option. Therefore take care to set the repeat time to a time that is longer than it takes for the Task to run (or suffer the consequences in terms of poor performance.)

Repeat After End Time

Repeats the plugin at user-defined intervals.  Enter the interval in the text field, and select the measurement of time from the pop-up list.  Every time task repeats, the next run time is set to the last run's end time + repeat_interval.

Notes:

1) Only the Main Plugin repeats and not the Parameter Plugin.

2) The repeat time is taken after completion of the plugin not the start, i.e., if a task takes 2 min. and the user sets an interval of 3 min., then the task will continue to run 3 minutes after it last completed (repeating approximately every 5 min.).

Creating a Task

To create a Task:

  1. Click the “Task Name” field and enter a name for the task in the Task Editor window.

Note:  Access the Task Editor window through any appropriate Manager.

  1. Select the “Description” field and enter a description if applicable.

Note:  A description might describe what this task does, or it may describe how often the task should be executed.

  1. Enter the name of the Param Plugin that should be executed as part of this task.  This field is optional.
  2. Enter the name of the Main Plugin that should be executed as part of this task.  This field is optional.
  3. Enter the name of the Page Viewer Plugin that should be executed as part of this task.  This field is optional.
  4. Enter the name of the Output Plugin that should be executed as part of this task.  This field is optional.
  5. Select the appropriate parameters in the fields of the Task Scheduling panel.
  6. Press the Save button or select File à Save to Database.
  7. Select File à New to clear the Task Editor window.
  8. Repeat Steps 1 through 8 to assign the rest of the plugins to tasks.
