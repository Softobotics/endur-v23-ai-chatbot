LINK SCREEN CONFIG DEFINITIONS

Overview

The Link Screen Config Definitions window allows users to define the following:

·         Default deal entry screen configuration for a toolset, instrument type, or template for users and interface groups

·         Default OpenLink Central configuration for users and interface groups

·         Default Presentation Module configuration for users and interface groups (available in V9.0R1 and above)

Accessing This Window/Screen

To access this window:

1.    Start OpenLink Central.

2.    Select OpenLink CentralàEdit Configuration Links from the menu.

The following window displays:

Other Ways to Access This Window

1.    Launch the Admin Manager.

2.    From the General Administration tab, select the Link Screen Configuration Definitions icon .

Tabs

This window contains the following tabs:

Tab

Description

Template/Instrument Type Links

This allows default deal entry screens for a toolset, instrument type, or template to be set for users and interface groups.

This tab displays by default when accessed from the toolset input screen or the Admin Manager.

Master Central (OpenLink Central) Configuration Links

This allows default OpenLink Central configurations to be designated for users and interface groups.

This tab displays by default when accessed from OpenLink Central.

Presentation Modules Configuration Links

This allows default Presentation Module configurations to be designated for users and interface groups.

This tab is available in V9.0R1 and above.

Fields

This tab contains the following fields:

Field

Description

View Type

Select the view type to which the configuration will be applied.

Pick list items are defined in the Deal Entry View Types static data window. System provided view types include:

View Type

Description

Standalone

Links that will be used in stand-alone deal entry screens. When linking an instrument type, template or CDE Link to a specific deal skin, this will be seen when opening stand-alone deal entry screens.

Trader Desktop

Links that will be used in the Trade Input panel in Trader Desktop. When linking an instrument type, template or CDE Link to a specific deal skin, this will be seen when opening a Trader Desktop containing a Trade Input panel.

Component

Links that will be used for the components in the Hybrid Deal Entry screen. When linking an instrument type, template or CDE Link to a specific deal skin, this will be seen on the Component tab of the Hybrid screen.

Gas Trading

Links will mimic the view on the Trade Blotter. To see these links, the “View Type” on the Trader Desktop Trade Input panel must be set to “Gas Trading”.

Component Panel

Links that will be used for the Component panel in the Hybrid Deal Entry screen. When linking an instrument type, template or CDE Link to a specific deal skin, this will be seen on the Component Panel of the Hybrid screen.

Data Explorer

Links that will be used in the Trade Input panel in the Trading Explorer Desktop. When linking an instrument type, template or CDE Link to a specific deal skin, this will be seen when clicking on a transaction in the Trading Explorer Desktop.

Toolset Name

If the Instrument Types button is selected, this field displays all instrument types within a toolset. “DEFAULT <Toolset Name>” represents the toolset, the names listed thereafter represent the instrument types within the toolset. An instrument type configuration takes precedence over a toolset configuration.

If the Templates button is selected, all templates of the toolset are shown. “DEFAULT <Toolset Name>” represents the toolset and the names listed thereafter represent the templates defined under the toolset When a screen configuration is linked to a template, that configuration loads when the template is selected.

If the CDE Link button is selected, all custom deal entry components within a toolset are shown.

Click the plus sign (+) button to expand or the minus sign (-) to collapse tree view.

An asterisk (*) displays beside the toolset/template if it has saved screen configurations.

Two asterisks (**) indicate the logged in user’s interface group.

OLF System

Displays the OLF standard screen configuration for the toolset/instrument type.

Tran Num

Displays when the Templates button is selected. Shows the Tran Num of the template.

System

Right-click to select the configuration to be used by all system users. This represents the public screen configuration. If a screen configuration is selected for the “DEFAULT <Toolset Name>”, it is the default configuration for all instrument types/templates for all users. If a screen configuration is selected for a particular instrument type or template, it is the default screen configuration for all users for the particular instrument type/template only.

<Interface Group>

Displays when the User Interface Groups button is selected. Screen configurations are selected for specific interface group(s). . If a screen configuration is selected for the “DEFAULT <Toolset Name>”, it means it is the default configuration for all instrument types/templates for the interface group. If a screen configuration is selected for a particular instrument type or template, it means it is the default screen configuration for the interface group and instrument type/template only.

<Users>

Displays if the Users button is selected. Select the screen configuration to be used by the user. This represents a private screen configuration. If both private and public configurations are defined, the private configuration takes precedence over the public configuration. If a screen configuration is selected for the “DEFAULT <Toolset Name>”, it means it is the default configuration for all instrument types/templates for the user. If a screen configuration is selected for a particular instrument type or template, it means it is the default screen configuration for the particular user and instrument type/template only.
