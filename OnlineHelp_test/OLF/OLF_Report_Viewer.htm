Report Viewer

Overview

The Report Viewer allows users to view and print all reports that have been generated in the system.  Historical reports can also be viewed by changing the report date.  The system stores all reports to a specific file for a specific date.

 

Accessing This Window/Screen

To access this window:

1.    Start the Operations Manager.

2.    Select the Daily Operations tab.

3.    Click the Report Viewer icon .

4.    The following window displays:

 

 

Other Ways to Access This Window/Screen

Option 1: From any Query window, select Misc à View Report.

Option 2: From the Trading Manager, select View à Report Viewer.

Buttons

Types

The left list box displays a list of report types.

Packages

The left list box displays a list of report packages.

Timestamp

Sorts the reports in the right list box by the last date and they were modified. The time stamp that is being displayed is from the script that generated the files rather than the file creation itself.  It sometimes takes a couple of seconds to write out a file, and there is a difference between the creation time of the file and the time of when the file was modified and passed to the report viewer.

Filename

Sorts the list of reports in the right list box by file name.

Fields

Displays only if “Types” is selected. It displays the suffix (i.e., extension) of the report type.

Displays a list of available file names (i.e., reports) for the selected report type/package. Highlight the report to display in the lower panel of the screen.

Displays the title of the selected report.
