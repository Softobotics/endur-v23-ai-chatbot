Command Line Options

The command line is one way (among several methods) of setting the values of System Wide Configuration (SWC) variables in the system. These commands are executed from the command line. Not all SWC variables may be set using this option. Note that command line arguments have a higher order of precedence than environment variables, which means that when variables are set using this option, the value of these variables (if set previously using batch files or shell scripts) are overridden.

When using this option:

·         Commands are preceded by “-“

·         A space is required after the command

·         Commands and arguments are case sensitive

·         Commands can be combined with other commands when executed (see the example below).

 

See Environment Variables.

 

The following are the commands that can be executed from the command line:

Command
Description

-afe “<service>”

Sets the AB_AFE_LAUNCH_SERVICE variable. The argument <service> is formatted as follows:

service name1 , arg1=value, arg2 = value ... | service name2, arg1 = value , arg2 = value ....

Available only in V8.1r1 and up

-d <database>

Sets the AB_LOGON_DATABASE variable. The argument <database> is the name of the database that will be used for the current system session.

-e <encryption flag>

Sets the AB_ENCRYPTION_FLAG variable. The argument <encryption flag> switches on or off the encryption mechanism, e.g., TRUE, to switch on encryption mechanism, or FALSE, to do otherwise.

-g <debug level>

Sets the DEBUG_SQL variable. The argument <debug level> is the debugging level that will be used, e.g., 1, 2, or 3.

-gui <gui type>

Sets the AB_GUI_TYPE variable. The argument <gui type> sets the GUI type, e.g., oi, or none.

-j <logon flag>

Sets the AB_LOGON_SERVER variable. The argument <logon flag> can either take the values of TRUE, or FALSE.

Note: This variable does not currently work.

-l <license file>

Sets the AB_RUNTIME_LICENSE_KEY_FILE variable. This argument specifies a license file that the system uses to determine the level of access to various functionalities within the system.

-makecfg

Generates a configuration file while starting the application. This command is useful in a “GUI-less” environment such as Linux.

-nb

Adds an icon to the Windows notification bar (System Tray). This icon can be used to launch Master as a background process and show "OpenLink Central" or shutdown the session. Auto shutdown will not be requested since the user can manage the session through the icon on the Windows Notification Bar. Example:

Master –nb –afe “Trader Desktop”

-nt_service

Sets the AB_NT_SERVICE_NAME variable. When this option is specified, master will run as a Windows Service.

-olfcfg <filename>

Sets the AB_OLF_CONFIG_FILE variable. The argument <filename> is the name of the OLF configuration file that will be passed to the master.exe program.

 

V6.0 Values:

Environment Variable used to set the Configuration File Name:

AB_NET_CONFIG_FILE   

Command Line:

master –netcfg <file>

 

V7.0 and up Values:

Environment Variable used to set the Configuration File Name:

AB_OLF_CONFIG_FILE

Command Line:

master –olfcfg <file>

 

-p <password>

Sets the AB_LOGON_PASSWORD variable. The argument <password> is the password that will be set as the default password.

-q <dbtype>

Sets the AB_DB_TYPE variable. The argument <dbtype> is the type of database that will be used as the default database type by the application, e.g., sybase, oracle, or mssql.

-s <server>

Sets the AB_LOGON_SERVER variable. The argument <server> is the name of the server that will be used for the current system session.

-t <debug_type_string>

Sets the DEBUG_TYPE_STATE variable. The argument <debug_type_string> is the string to activate/deactivate Debug Types.

For a list of the possible enumerations, such as DebugType_DB, see the Error Log Viewer

-u <username>

Sets the AB_LOGON_USER variable. The argument <username> is the name of the user that will be set as the default user.

 

Example

master –u credit –p credit

start master –u trader1 –p trader1

 

 

Example of Environment Variables / Command Line Options

1) Set DEBUG_TYPE_STATE="-*,+17"

 

2) -g3 -t "-*, +OPENLINK_CENTRAL"

The -g3 is to set Debug to High and the -t options are to enable some of the Open Link Central Debug Messages.

 

3) master -afe "Trader Desktop, screen_name=my_screen"

 

The AFE id of "Trader Desktop"  is 300 so the command above can be rewritten

 

master -afe "300, screen_name=my_desktop"
