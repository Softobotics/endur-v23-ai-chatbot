Script Addin Function Configuration

Overview

The Script Addin Function Configuration window is where users can configure Script Addins.

Note: This functionality is purely for OpenLink internal use only. Users see nothing by default. This functionality requires a license key to enable any/all pieces. This functionality is intended to allow for OpenLink to distribute updated functionality for Scripts without requiring customers to take a full release. This cannot be used for customers to create their own Script Functions. (v90r1 and later)

Note: This page is for v90r1 and later. For v82r1 and earlier, see AVS Addin Function Configuration

Accessing This Window/Screen

This window can be accessed via multiple paths in the system.  This procedure is just one example of how to access the Script Editor.

  1. Open the Trading Manager.  The Trading Manager browser window displays.
  2. Select Script à Script Editor.  The Script Editor window displays.
  3. Select File à Script ADDIN Configuration.
