Configure View

This page is applicable to V10.1r1 and below. Click here for V10.2.1 and above.

Overview

The Configure View window is one of the screens that appear in numerous functionalities of the system. This window allows users to configure the table from which this window is accessed. All tables in the system have default settings, i.e., the columns that display by default and how data are presented in the table. From the Configure View window, users can modify the system default settings, i.e., add or remove columns that will be displayed, rename columns, and set up various grouping, sub-totaling, and formatting features. The user has the option to save the configuration for later use.  It can also be set as a default and be applied every time the table is accessed and used. The column titles listed vary and depend on the table that is being configured.

 

Accessing This Window/Screen

This window is accessed from various functionalities of the system. For illustration purposes, the following is an example of how it is accessed:

1.    Start the Trading Manager.

2.    Select View à Transaction Field Viewer. The Transaction Field Data window displays.

3.    Select Configure à Configure.

4.    The following window displays.

Fields

This window contains the following fields:

Field

Description

Search Column Title/Name

Enter the name or title of the column to search and press the <Enter> key. The first name that matches the search criteria is highlighted. Press the <Enter> key again to display the next match.

Display Setup

Displays the display setup of the loaded configuration. This field defaults to “None”, which means that the setup is currently set at default.

To create a new display setup, see the procedure below.

To load a display setup, right-click the field to display the pick list of available display setups. Select the setup to load.

 

Gray Scale

The gray scale color; right-click the field to select the row color.

Font Size

The font size of the text; right-click the field to select the size of the font.

Summation Row

The color of the sum break rows; right-click the field to select the row color.

 

 

Column Title

The title of the column that will be displayed in the table.

Display

Toggle to indicate whether the data field will be displayed in the table. Place a checkmark to display the column.

Sort#

The sort key of the table. To define several sort keys, rank the primary sort key with “1”, the secondary key “2”, and so on. For example, giving a 1 for Status and 2 for Deal # makes Status the primary key and Deal # the secondary key.  The table to be displayed will be sorted first by Status and then by Deal #.

 

Please note that in a Table/Blotter you cannot sort in descending order (i.e., 1-D) and sum rows. The sum rows only works when a column is sorted in ascending (i.e., 1) order.

Sum Break

Groups the data by the checked field. Place a checkmark on the data field to indicate how data will be grouped.

Show Subtotal

Displays the total for each group, as defined by the “sum break” field.

Show Total

Generates a row with a sum of the checked data field across all rows.

Column Type

Data type of the field.

Format

The formatting used when displaying the data field.  Users can choose from a pick list of formatting appropriate for the specific data type. 

Param1, Param2, Param 3, Param 4, Param 5

Contains additional parameters required for the “Format” column.  For example, for a Date Format (FMT_DATE), additional parameters specifying the order and the separator, and the locale of the date, are required.

Column Name

Internal name of the data field.

Column Formula

Displays the formula defined for the formula column.

 

Changing the Order of the Columns

To reorder the columns,

1.    Highlight the row to move by clicking the leftmost cell.

2.    Press the down arrow key to move the row down the list or the up arrow key to move the row up the list.

 

In V8.0r2 and up, the user may sort the columns by simply dragging and dropping the column header of a field to its new location. When the column is being dragged to its new location, a red arrow pointing in between the columns where the column will be inserted is displayed.

Creating a New Display Setup

To create a new display setup,

1.    Click the right-pointed arrow button located beside the “Display Setup” field. Additional fields display to define the font size and the color of gray scale and summation row.

2.    Select the desired color for the rows and font size of the text.

3.    Enter a name for the setup in the “Display Setup” field.

4.    Select File à Display Setup à Save to save the display setup.

5.    Select File à Save to save the display setup in the configuration.

 

Adding a Formula Column

To add a formula column to the table,

1.    Select Formulas à Add Formula Column. The Add Formula Column window displays.

2.    Enter details of the column formula.

3.    Select File à Save to save the new column in the configuration.

Setting a Default Configuration

To set the default configuration for a table,

1.    Select File à Set As Default. The Set Default window displays.

2.    Put a checkmark to the configuration that will be set as the default configuration.

3.    Click the OK button. The configuration is used automatically by the table the next time it is loaded on screen.
