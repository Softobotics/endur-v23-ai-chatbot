Plugin/Script Bulk Export

Overview

This window is used to export both plug-ins and scripts. Plug-ins are exported into folders that are named after the project to which they belong. Scripts are exported as .mls files. In either case an XML config file (.xml) is generated that is used for bulk import by another user or for re-importing on the machine of origin.

Note: (for V10.0r2 and later): When importing or re-importing scripts (.mls files) that were created using Bulk Export, use only the generated package .xml file. This is because a bulk exported file name includes path information for exported scripts that is used by the .xml file during import. The single .mls files should not be selected for Bulk Import because the treatment of file names can result in erroneous file names and duplication.

Accessing This Window/Screen

This window can be accessed via multiple paths in the system. Listed below are two options:

1.    Select the System Administration tab from Admin Manager.

2.    Select the Plugin Bulk Export icon.

or

1.    Open the Trading Manager.

2.    Select Script à Script Editor. The Script Editor window displays.

3.    Select File à Bulk Export.

Fields

This window contains the following fields:

Field

Description

*Config File Name

Name for the generated package .xml file. Default name is scripts_config_data.xml.

*Export Path

Destination path for the exported files.

Pick list of Plugin/Script names in the OLF system.
