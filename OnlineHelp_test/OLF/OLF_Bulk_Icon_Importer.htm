Bulk Icon Import

This window allows multiple user icons to be imported into the system at one time. User icons imported into the system can be used by the Data Explorer.

 

Note: For information on importing more than one user icon at a time, refer to Single Icon Import.

 

Accessing This Window/Screen

To access thiswindow:

1.    Start OpenLink Central.

2.    Select Launch Available Services from the menu.

3.    In the Filter Services field, enter the service name “Bulk Icon Importer.”

4.    Select the service from the Available Services panel and click Launch.

The following window displays:

Import From Panel

This panel contains the following fields:

Field

Description

Directory

Displays the name of the directory containing the icon files to be imported. Used in conjunction with the Browse button.

Look in Sub-Folders

Select this checkbox to search sub-folders of the main folder selected in the Directory field for icon files to import.

Import Files of this Type

Allows the user to choose the image type for the icon files to be imported. Only files of the type(s) selected in this field will be imported. Options are JPEG, Bitmap, GIF, or All Image Files (i.e., JPEGs, Bitmaps, and GIFs).

 

Import Options Panel

This panel contains the following fields:

Field

Description

Overwrite Existing Icons

Select this checkbox to overwrite previously imported icon files of the same name with newer versions of the files.

Options For Converting File Name to Icon Name

Select the desired option for naming the imported icons within the system. Choices are:

·         Icon Name will be Upper Case File Name

·         Icon Name will be Lower Case File Name

·         Icon Name will be the same as the File Name

Importing Multiple Icon Files

To import multiple (i.e. bulk import) user icon files:

  1. Click the Browse button and select the folder containing the files to be imported.
  2. If applicable, select the Look in Sub-Folders checkbox.
  3. In the Import Files of this Type field, choose the type of image files to be imported.
  4. If applicable, select the Overwrite Existing Icons checkbox.
  5. Select one of the Options for Converting File Name to Icon Name.
  6. Click Import.

The Icon Import Status window displays, containing detailed information about the files successfully imported, as well as listing the files that were not imported successfully.
