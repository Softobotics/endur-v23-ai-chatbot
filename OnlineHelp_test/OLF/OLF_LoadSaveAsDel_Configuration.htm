Overview

This window is used throughout the system by functionalities that involve loading, saving, setting a default, or deletion of a configuration. The title or name of the window depends on its functionality, e.g., the window is titled “Save As” if saving a configuration, “Load” if loading a configuration, “Delete” if deleting a configuration, and “Set Default” if setting a default configuration.

 

Accessing This Window/Screen

This window may be accessed from various functionalities of the system. For illustration purposes, the following is an example of how it is accessed:

1.    Start the Trading Manager.

2.    Open any deal input window.

3.    Select Misc à Payment Formula. The Formula window displays.

4.    Select File à Save Template.

5.    The following window displays:

 

 

Menu Items

None.

 

Buttons

This window contains the following buttons:

Button

Description

Public

Toggle to save the configuration as public or private. Put a check mark to save it as a public configuration. A public configuration can be used by all users while a private configuration can only be used by the user who created it. This field displays only if saving a configuration.

OK

Click this button to perform any of the following:

§  Save the new configuration

§  Save changes in the configuration listing

§  Load an existing configuration

§  Set a default configuration

Cancel

Closes the window without saving any changes or loading the configuration.

 

Fields

This window contains the following fields:

Field

Description

Default

Sets the configuration as the default configuration. Put a checkmark to set it as the default configuration. This field displays only if setting a default configuration.

File Name

Name of the configuration.

Config Type

Indicates whether the configuration is private or public.

 

Owner

User ID of person who last updated the configuration.

Last Update

The date and time the configuration was last updated.

afs_id

The unique ID number for the Application File System (AFS) record.

Complete File Name

The AFS name for the saved configuration. This entry can also be viewed and/or deleted from the AFS Viewer.

<configuration name>

Input field to enter the name of the configuration to be saved. If the name already exists, the system will warn and ask the user if the existing configuration will be overwritten. This field displays only if saving a configuration.

 

Saving a New Configuration

To save a new configuration,

1.    From the Save As window, enter the name of the configuration in the text entry field located at the bottom of the screen.

2.    Check or uncheck the Public checkbox to make the configuration public or private, respectively.

3.    Click the OK button to save the configuration. The new configuration is added in the configuration listing.

 

Loading a Configuration

To load a configuration on screen,

1.    From the Load window, highlight the configuration to be loaded.

2.    Click the OK button. The configuration loads on screen.

 

Setting a Default Configuration

To set a default configuration,

1.    From the Set Default window, highlight the configuration to be set as the default configuration.

2.    Click the OK button. The configuration loads on screen and set as the default configuration.

 

Deleting a Configuration

To delete an existing configuration,

1.    From the Delete window, highlight the configuration to delete.

2.    Click the OK button. The configuration is deleted from the configuration listing.
