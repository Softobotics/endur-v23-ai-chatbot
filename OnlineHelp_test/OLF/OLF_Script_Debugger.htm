Script Debugger

Overview

The Script Debugger is a helpful tool that users can run when they encounter run time errors or erroneous data results.  It allows users to set “break points” in the scripts at which to stop.  The user can then step through lines of code examining variables and tables, to try and find what caused the error. 

 

Accessing This Window/Screen

To run a script in Debug mode:

  1. Open the Trading Manager.
  2. Right-click on the Abort Task button and select “Debugger.”
  3. Select a task from the picklist that appears.
  4. Click on the Load Task button.
  5. The Script Debugger screen displays with the AVS script for the task that was selected.

Or

  1. Open a script using the AVS Script Editor.
  2. Add the line #SDBG to the very first line of code and recompile it. 
  3. When you next run your task it will stop execution of your code at the very first line and pop up a Debugger Window.
  4. This allows you to step through your code and set breakpoints, etc. 

Note:  Remember to remove #SDBG from the code when you have finished debugging.

Fields

This window contains the following fields:

Field

Description
Name

The name of the script stored in the database.

Type

The type of script.  The choices are:

Type
Description

Param Script

A Parameter script is used to prepare information to be passed to a main script.  The table argt is used to hold date to be passed to a main script.  Parameter scripts can, but are not normally, run without a main script in a Task.

Main Script

A Main script is the main script that contains the bulk of the reporting or process-specific AVS code.  A main script may be designated to run alone in a Task.

Page Viewer Script

A Page Viewer script is typically used to set the subscriptions and activate the Page Viewer

Output Script

An Output Script is a script that runs locally in the Trading Manager after the main script has run. 

The order in which scripts in a task are run is:

First: Display Script

Second: Param Script

Third: Main Script

Fourth: Output Script

The user ID to which the task is assigned.

A list box containing the commands of the script.

A list box that displays the messages that the system sends as the script is being debugged.

 

<sdbg> Shell

The shell "terminal" is the lower text area in the sdbg window.

Type help at a <sdbg> prompt.  A list of sdbg commands, including print, breakpoint, continue, step, finish, skip, set, and help displays.

 

Note:  Print [variable] should be print [expression].  An expression can be of any form acceptable in a script, such as x * (y+3), 10*growth(rate, dcf) , and so on.

 

Abbreviation:  When a command is typed, its prefix can be used as long as this prefix does not confuse another command above it in this list e.g., use 's' for step, 'sk' for 'skip', and 'se' for set.

 

Command history is supported.  You can either move the cursor back to a previous command and hit RETURN/ENTER, or, use M-P, M-N to navigate along command history.
