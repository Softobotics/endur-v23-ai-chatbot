Groups

Overview

The Groups window allows the user to create new, rename, and delete existing groups in a window. This screen is used by the several functionalities in the system such as Portfolio Groups and Entity Groups.

 

See also:

Portfolio Groups

Entity Groups

 

Accessing This Window/Screen

This window is accessed from several functionalities in the system. To illustrate how it is accessed:

1.         Start the Admin Central Sidebar.

2.         If not yet selected, click the General Administration tab.

3.         Click the Portfolio Groups icon .

4.         Select Groups à Setup Groups

The following window displays:

 

Menu Items

None.

 

Buttons

This window contains the following buttons:

Button Description
<Select Group> Displays a pick list of groups currently defined in the system. The name that appears on this button is the group currently selected on the pick list.
Displays the list of items defined for the group in the Group Name field, if any.
Deletes the group currently loaded in the Group Name field.
Saves the modifications and closes the window.
Closes the window without saving any changes.

 

Field Items

This window contains the following fields:

Field Description
Group Name Displays the name of the group selected in the Select Group button. This is also a field  to input the name of a new group or change the name of an existing group.

 

How To: Adding a New Group

1.         Click the Select Group button and select “ADD NEW GROUP” from the pick list. The “Group Name” field clears.

2.         Input the name of the new group in the Group Name field.

3.         Click the OK button to save the new group. The window closes and the new group column is added to the Portfolio/Entity Groups window.

 

How To: Deleting an Existing Group

To delete an existing group:

1.         Click the Select Group button and select the group to delete from the picklist. The group’s name displays on the “Group Name” field.

2.         To check the items that belong to the group prior to deletion, click the List <Items> In Group button. The list displays all the items defined for the particular group.

3.         Click the Delete Group button to delete the group. Note that items are not deleted when groups are deleted.

4.         Click the OK button to save changes. The window closes and the column of the group is removed from the Portfolio/Entity Groups window.

 

How To: Renaming an Existing Group

To rename an existing group:

1.         Click the Select Group button and select the group to rename from the pick list. The group’s name displays on the “Group Name” field.

2.         Edit the name of the group.

3.         Click the OK button to save the modification.
