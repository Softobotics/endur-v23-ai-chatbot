Script Global Variables

Overview

Shows the Global Variables which may be used in Grid Point formulas.

Note: This page is for v90r1 and later. For v82r1 and earlier, see AVS Global variables.

Accessing This Window/Screen

To access this window:

  1. Start the Market Manager.
  2. Right-click on one of the index nodes and scroll down to Definition.
  3. The Standard Official (or Custom) Index window appears.
  4. Select Help à Formula Global Variables.

The following window displays:

Menu Items

This window contains the same menu items as the Table Viewer.

Buttons

This window contains the following buttons:

Button

Description

Prints the current window.

Fields

This window contains the following fields:

Field

Description

Variable Type

Indicates the type of variable displayed.

Variable Name

Displays the field in the data table that is displayed.

Initial Value

Displays the default value.
