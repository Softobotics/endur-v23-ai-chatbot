OPEN FILE FROM DIrectory Browser

Overview

The Open File From Directory Browser window has the same functionality as the Directory Browser window—it allows users and administrators to find and maintain from a single screen the files in the OLF virtual file system.

 

Accessing This Window/Screen

This window may be accessed from various functionalities of the system. For illustration purposes, the following is an example of how it is accessed:

1.    Start the Trading Manager.

2.    Select File à Query. The Trading Query displays.

3.    Click the Open Query From Browser icon .

4.    The following window displays:

 

 

Menu Items

This window contains the following menu items:

Menu

Item

Description

File

Edit Directory

Opens the New Directory Window. This allows the user to edit the properties of the directory that is currently selected.

 

New Directory

Opens the New Directory Window. This allows the user to create a new folder or sub-directory under the directory that is currently selected.

 

Up Directory

Selects the parent folder of the directory that is currently selected.

 

Home Directory

Selects the default directory, which depends on the functionality this window was access from. For example, if this window was opened from the Trading Query, the home directory would default to “/Query”.

 

Print

Prints the current window.

Help

Help

Displays the system Help files.

 

Fields

This window contains the following fields:

Field

Description

Current Directory

Displays the full path of the selected folder in the Directories table.

Directories

node_name

Lists the directories. Only the files contained in the selected directory are displayed in the Contents of Directory listing. An open folder indicates that the directory is selected.

Contents of Directory

name

Name of the file.

Database Table.Column: dir_node.node_name

node_type

Type of file, e.g., task, script, query, screen configuration, etc.

Database Table.Column: dir_node.node_type

owner

User ID of person who controls or owns the file.

Database Table.Column: dir_node.owner

security_group

The security group who controls the file. This group has special privileges over and above the privilege defined for the “public”.

Database Table.Column: dir_node.group_id

category

Category of the file. The category depends on the file type.

Database Table.Column: dir_node.category

parent_node_id

The ID number of the directory where the file resides.

Database Table.Column: dir_node.parent_node_id

data_id

The sequence number of the file.

Database Table.Column: dir_node.client_data_id

user_permiss

Permissions granted to the owner of the file.

Database Table.Column: dir_node.user_permiss

group_permiss

Permissions granted to the security group.

Database Table.Column: dir_node.group_permiss

public_permiss

Permissions granted to all users (i.e., the public) of the file.

Database Table.Column: dir_node.public_permiss

update_user_id

The User ID of the person who last updated the file.

Database Table.Column: dir_node.update_user_id

last_update

The date and time the file was last updated.

Database Table.Column: dir_node.last_update

version

The version number of the file. The version number is incremented to 1 whenever the properties of the file is modified and saved.

Database Table.Column: dir_node.version

grouping

The ID number of the toolset in which the file applies.

Database Table.Column: dir_node.grouping

node_id

The ID number of the file.

Database Table.Column: dir_node.node_id

Lower Panel

Filename

Displays the directory and name of the highlighted file in the Contents of Directory table.

File Type

This field filters the file to display in the Contents of Directory table, e.g., if “Script” is selected, only scripts will display in the Contents of Directory table for the selected directory. This field defaults to the category of the selected directory.

Delete Directory. Deletes the selected directory.

Load

Displays the details of the file loaded in the “Filename” field in the appropriate screen, e.g. Directory Window (for Crystal or OpenComponent, types), Script/Task Editor (for scripts/tasks), Table Viewer (for screen configurations) or Query Manager (for queries). To load the file in the “Filename” field, highlight the file from the Contents of Directory table.

 

Note: Another way to load a file is to double-click the file in the Contents of Directory table.

Cancel

Closes the window.

 

Editing Scripts/Tasks/Queries/etc.

To edit scripts, tasks, queries, etc.,

1.    From the Directories table, click the folder (i.e., directory) to search. The files of the selected directory displays in the Contents of Directory table.

2.    Double-click the row to edit in the Contents of Directory table. The applicable screen of the file displays.

Note: Another way to open the file is to highlight the row and click the Load button.

3.    Edit and save the file.
