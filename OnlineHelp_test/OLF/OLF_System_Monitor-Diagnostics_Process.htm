System Monitor - Diagnostics - Process Table

Overview

This window displays details regarding system processes running on the local machine.

 

The following Security Privileges are applicable to this window:

Privilege ID

Privilege

29300

Access Diagnostics Tab

29305

Kill Selected Processes

 

 

See System Monitor

 

Accessing This Window/Screen

To access this window:

  1. Start the OpenLink System.
  2. From OpenLink Central, click the System Monitor icon
  3. Select the Diagnostics tab.
  4. Select the Process Table sub-tab.

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

 

Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.

 

Buttons

This window contains the same toolbar buttons as the System Monitor. This tab includes the following buttons:

Button

Description

Fields

This window contains the following fields:

Field Item

Description

Display Name

The name of the process as seen by the end-user.

Process Name

The internal system name of the process.

Status

The status of the selected process. This field typically shows “Running”.

Process ID

The system-designated Process ID (PID).

Process Size

The process size, in kilobytes.

VM Size

The system virtual memory size for the process.

ECOM Sessions

Shows the subscriptions for the messaging tools. The data in this column is of type ‘Table’. Data is accessed by double-clicking the ‘grid’ icon to open the data table.

JVM Initialized

An indicator as to whether the process is enabled for Java scripting.

JVM Debug Port

The port for which Java scripting debugging can be accessed.

Internal Data

System data specific to the selected process. The data in this column is of the type ‘Table’. Data is accessed by double-clicking the ‘grid’ icon to open the Internal System Data table. Double-click an item within the table to launch a data table specific to the selected item.
