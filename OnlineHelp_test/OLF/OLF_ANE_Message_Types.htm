TRAN_INSERT

This is what is seen when a trade is processed to a new (different) status.  This is used by the Trade Blotter and Trading Manager Brower and tells them to update.  The message is of type "Table" and contains information about the deal, e.g. COMM-Phys., FX, Offset deals.
