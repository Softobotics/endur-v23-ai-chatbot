System Monitor - System – graphics properties

Overview

This window shows display variable details. While the data is read-only, the values shown can be configured using the following external environment variables:

 

Variable

Description

AB_GRAPHICS_THEME

This variable determines the theme files to be used for default widget properties. These files determine most of the widget graphics properties that can be set. This variable is set in the runscript.

AB_GUI_PICKLIST_INDICATOR

This variable determines if menu fields and calendar pop ups will show with down arrows and calendar icons, respectively. This variable is set in the runscript.

AB_OLF_DEF_FONT

This variable determines the font to be used throughout the application. This variable is configured in the System Wide Configuration.

Contact the OpenLink Support Desk for instruction in changing these variable settings.

Accessing This Window/Screen

To access this window:

  1. Start the OpenLink System.
  2. From OpenLink Central, click the System Monitor icon
  3. Select the System tab.
  4. Select the Graphics Properties sub-tab.

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.
