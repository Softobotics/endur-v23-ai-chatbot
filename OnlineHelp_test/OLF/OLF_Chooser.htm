CHOOSER DIALOG BOX

Overview

The chooser dialog box is used throughout the system. It is used to select items from a list. It can contain many different types of data but is always used the same way.

Regardless of the type of data used, the principle remains the same:

  • If an item is in the Selected column, it will be included in the system’s processing
  • If an item is in the Available column, it will not be included in system processing but can be added

Accessing the Dialog Box

The OLF Chooser window is accessed from many different locations in the system. For discussion purposes, here is an example of how it is accessed:

  1. Open Admin Manager.
  2. The General Administration tab displays.

Fields For The First Type of This Window

The first type (first example) of this window contains the following fields:

Field

Description

Selected _________ (in this example, “Selected Instruments”

Displays a list of items that the user has selected to be used in system processing.

Available ________ (in this example, “Available Instruments.”)

Displays a list of items that will not be included in the system processing but are available to be used, if the user chooses to add them.

Adding Items To The Right Side Column

  1. Select the items in the left side column to be added.
  2. Click the Add button, or click Add All to add all items in the left side column.
  3. Click OK.

Removing Items From The Right Side Column

  1. Select the items in the Right Side column to be removed.
  2. Click the Remove button, or click Remove All to remove all items in the Right Side column.
  3. Click OK.

Alternately, you can double-click on any item to move it from one side to another.
