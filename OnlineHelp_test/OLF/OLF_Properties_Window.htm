PROPERTIES WINDOW

Overview

The Properties Window allows users to set and save the location and security privileges for a file such as a plug-in/script, task, screen configuration, query, etc.

Accessing This Window/Screen

This window may be accessed from various parts of the system. For illustration purposes, the following steps are provided:

1.    Start the Trading Desktop Explorer or Trading Manager.

2.    Open any deal input window.

3.    Click the Pricer icon.  The Pricer window of the instrument displays.

4.    Click the Quick Simulation icon.  The Simulation Results viewer displays.

5.    Click the Export to Script icon.

The following window displays:

Menu Items

None.

Buttons

This window contains the following buttons:

Button

Description

Read

Toggle to allow the owner, security group, or all users to read the file. If checked, the owner, security group, or the public is given the access to read the file.

Write

Toggle to allow the owner, security group, or all users to edit the file. If checked, the owner, security group, or the public is given the access to edit the file.

Execute

Toggle to allow the owner, security group, or all users to execute or run the file. If checked, the owner, security group, or the public is given the access to run the file.

Save

Saves the settings in the window.

Cancel

Cancels any modifications to the settings and closes the window.

Field Items

This window contains the following fields:

Field

Description

Name

Input the name of the file.

Version

Displays the version number of the file. The version number is incremented to 1 whenever the file is modified and saved.

Directory

The folder the file will be saved or is located. Right-click the field to display a pick list of directories. Select the directory where the file will be saved.

Config Type

This field displays only when saving or modifying the properties of a Trader Desktop screen configuration. It displays the screen configuration type that is being saved or modified, e.g. Desktop Config, Multi Trade Panel Config, Toolbar Config, etc.

Full Path

Displays the location or full path of the file.

Owner

The user ID of the person authorized to read, write, or execute the file. Right-click the field to display a pick list of users. Select the user to give access rights.

Security Group

The security group authorized to read, write, or execute the file. Right-click the field to display a pick list of security groups. Select the security group to give access rights.

Public Permissions

This represents the security settings for all users. Check the appropriate checkboxes to authorize the public to read, write, or execute the file.

Setting the Property of a File

Follow the steps below to set the property of a file:

1.    Enter the name of the file in the “Name” field.

2.    Select the location and define the privileges of the user, security group, or all users for the particular file.

3.    Click the Save button to save settings. If the name of the file already exists, a message will display if the existing file will be overwritten. To save the file as another file, enter a different name for the file.
