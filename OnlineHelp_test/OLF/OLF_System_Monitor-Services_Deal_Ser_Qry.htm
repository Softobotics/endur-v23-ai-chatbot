System Monitor - Services – Deal Services Query

Overview

The System Monitor – Services tabs work with the Services Manager module. Many of the components viewed in this tab have been previously configured in the Services Manager.

This tab provides a query tool that can be utilized to view services by process and transaction number.

Access to this window is controlled by Security Privilege #29280, Access Deal Services Query Tab.

See Also

System Monitor

Accessing This Window/Screen

To access this window:

  1. Start the OpenLink System.
  2. From OpenLink Central, click the System Monitor icon
  3. Select the Services tab.
  4. Select the Deal Services Query sub-tab.

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.

Buttons

This window contains the same toolbar buttons as the System Monitor. This tab includes the following buttons:

Button

Description

Clear

Removes all transaction, process and service data from the screen.

Load All Logged Items

Retrieves and displays all transactions recorded in the system logs.

Query Deals

Returns the system Query window. This screen is used to specify search criteria and parameters.

Fields

This panel contains the following fields:

Field

Description

<Transaction Number/Process/Service>

Shows transactions, processes and services in tree-view format. “Transactions” are shown at the highest level while “Processes” and “Services” are shown in the lower levels.

External Legal Entity

Displays the name of the external legal entity associated with the selected service.

Response

Displays job response data.

Facility Name

A user-defined group of one or more exposure definitions associated with the selected service.

Exposure

User-defined credit line and trading limit criteria.

Usage

The accumulated exposure for the credit line associated with the selected process. It is the up-to-the-moment sum of all the exposures of all deals that hit this line. This number can be positive or negative.

Limit

Displays the amount of exposure an organization is willing to risk.

Exp Line ID

A unique, system-assigned identifier of the credit line.

Right-Click Menu

Right-clicking on any row within the table returns the following menu items:

Item

Description

Collapse Group

Hides the processes and services to the transaction level of the group from which the menu was accessed.

Expand Group

Displays the processes and services contained in the group from which the menu was accessed.

Collapse All

Hides all the processes and services in all the groups.

Expand All

Expands all the services in all the groups.

Expand To Transaction No

Hides the processes and services in all the groups.

Expand to Results Type

Expands all the transactions to the process level.
