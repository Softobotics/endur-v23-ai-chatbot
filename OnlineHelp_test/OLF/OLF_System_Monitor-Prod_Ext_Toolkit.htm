System Monitor - Product Tools - Toolkit

Overview

This screen details the underlying components required for use of the OpenLink Toolkit, including the required controls and dlls for Toolkit development and execution. This window is comprised of the following panels: Licensed For, Toolkit DLLs, Registered Controls, Tookit QA App, and Toolkit Processes.

This screen is intended for use by Information Technology professionals when debugging Toolkit functions. Toolkit access requires the purchase of a separate license key.

In v6.0 and below, the Product Tools tab is named Product Extensions and contains the OpenConnect Monitor sub-tab. As of V8.0r1 and up, the OpenConnect Monitor sub-tab has been moved to the System Monitor à Services tab and renamed Connex Grid Monitor.

Access to this window is controlled by the following Security Privileges:

Accessing This Window/Screen

To access this window:

  1. Start the OpenLink System.
  2. From OpenLink Central, click the System Monitor icon
  3. Select the Product Tools tab.
  4. Select the Enterprise Toolkit sub-tab.

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.

Buttons

This window contains the same toolbar buttons as the System Monitor. This tab includes the following buttons:

Button

Description

This button executes a sample OpenJVS plugin to validate that the OpenLink System is configured properly to run OpenJVS plugins.

This buttons is available in v9.1r1 and up.

Launch the .Net Quality Assurance Application

This tests if the toolkit is functional at its most basic level. To use it, click the Launch .Net QA button. Select options from the Attach Settings panel and click Run Test. The test results are shown in the Attach Mode Test Result panel. To save the test results, select the Save Output to File button.

This button is available in v8.1r1 and above.

Launch the C Quality Assurance Application

This tests if the toolkit is functional at its most basic level. This is a Windows Console application. To use it, click the Launch C QA button. The console window displays and scrolls with the testing process. When the testing is complete, press the Enter key to exit the console window.

This button is available in v8.1r1 and above.

Launch the Java Toolkit Assurance Test. Click the Run Test button. Test results can optionally be saved.

This buttons is available in v9.0r1 and up.

Launch Visual Basic 6 Quality Assurance Application

This tests if the toolkit is functional at its most basic level. To use it, click the Launch VB6 QA button. The system will then prompt for a Log File name. Enter the filename and click OK to start the test. The main screen will indicate if the test was passed or failed.  For more information on the test, view the log file.

This button is available in v8.1r1 -8.2r1.

Fields

Licensed For

This panel contains the following fields:

Field Item

Description

{Licensed For}

This field shows the type of license installed, either Professional (Pro) or Standard. The professional installation includes Standard and will show both “Professional” and “Standard” in this field.

Toolkit DLLs

This panel shows the details around the core Toolkit dlls.

This panel contains the following fields:

Field Item

Description

Filename

Displays the name of the selected dll file.

Size

Displays the size of the selected dll file.

Version

Displays the file version of the selected dll.

Date

Displays the date the selected dll was created.

Location

Displays the place of the dll within the application.

Registered Controls

This panel shows the details around the user Toolkit controls.

This panel contains the following fields:

Field Item

Description

OCX/DLL

The name of the file used to attach to the locally running application session for development and execution of any custom developed toolkit application.

GUID

The unique Windows registry ID for the selected file.

Size

Displays the size of the selected file.

Version

Displays the registry version of the selected file.

Date

Displays the creation date of the selected file.

Location

Displays the location where the selected control file was installed.

Toolkit QA App

This panel contains the following fields:

Field Item

Description

Filename

The name of the quality assurance application that is run when the associated launch button is clicked.

Size

Displays the size of the QA file.

Version

Displays the version of the QA file. As of v81r2 this is not functional.

Date

Displays the creation date of the selected file.

Location

Displays the place of the selected file within the application.

Toolkit Processes

This panel contains the following fields:

Field Item

Description

Name

The name of the toolkit function.

PID

The unique system process id for the toolkit function.

Process Size

The size, in kilobytes, of the toolkit function.

VM Size

The amount of virtual memory, in kilobytes, of the toolkit function.
