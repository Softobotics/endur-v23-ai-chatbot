BROWSER

Overview

The Browser is a system navigation interface used in the Trading, Market, Credit, Risk, and Accounting Managers to graphically depict items.  The Trading Manager browser shown below will be used as an example to describe components that are common to all browser windows.

 

 

Common Browser Components

Examine the Trading Manager browser window.

§  The browser displays a tree structure from left to right.  In most cases, the left side of the tree structure contains the most generalized items.  Items become more specific as the tree progresses to the right.

§  The boxes shown in these browsers are referred to as nodes for purposes of this documentation.  Each individual node has a variety of functionalities that are available to the user, depending on which browser (i.e., Trading, Market, Accounting, etc.) is being viewed.  For example, the Market Manager Browser will have a different set of functions available than the Trading Manager browser.

§  The left side of the browser is the Browser Overview.  The Browser Overview displays a thumbnail view of the nodes that have been loaded through a query. Nodes are arranged in a tree structure. The left most node contains the all-encompassing group node or the parent node. The parent node may contain child (and sub-child) nodes which may extend to the right of the parent node.

§  The black rectangle within the Browser Overview is the Focus Box.  It controls which items are displayed on the right side of the window.  This feature is especially helpful in trading desk situations, in which there may be literally hundreds of deals displayed in the system at once. 

§  By clicking on and moving the rectangle in the left panel, the user controls what is displayed in the right panel.  This feature is very WYSIWYG, in that the nodes displayed in the box in the left panel are exactly the ones shown in the right panel. 

§  The right side of the browser is the Focus View.  The Focus Box can be moved with the mouse to control which items are displayed in the Focus View.  The left or right mouse button can also move the Focus Box by clicking on a different area within the Browser Overview.  The vertical and horizontal scroll bars at the right and bottom of the Focus View control which items are displayed in the Focus View.

 

Browser Cursor Icons

The browser cursor changes to reflect different functions within the browser.

Cursor

Function

The Crossbar appears when the cursor is within the Focus Box of the Browser Overview.  Click and drag the mouse to move the Focus Box, thereby shifting focus to another area within the overview.

The Right Arrow appears in the Focus View when the cursor is on the right-most side of a node that is a “parent” with “children”. The “children” in this case are not currently displayed.  Click the node when the cursor is a right arrow to display its children.

The Left Arrow appears in the Focus View when the cursor is on the right-most side of an item that is a “parent” with “children”. The “children” in this case are currently displayed.  Click the node when the cursor is a left arrow to hide its children.

The Hand appears when the left mouse button is held down while the cursor is in the background of the Focus View.  Move the mouse while holding down the left button to shift focus to another area of the overview.

The Magnifying Glass appears in the Focus View when the cursor is on a node for which there is an input window.  Click an item when the cursor is a magnifying glass to open the input window of the node.

The Notepad is displayed when the cursor is placed over the Grid symbol/icon on a node. The Grid indicates that the node contains a table.  A number in the upper right hand corner that indicates how many items are present usually accompany this grid.  Click on this icon to display the table.
