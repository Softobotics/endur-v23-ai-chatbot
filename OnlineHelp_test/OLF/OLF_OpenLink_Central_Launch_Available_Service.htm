Launch Available ServiceS

Overview

The Launch Available Service window provides a listing of all available system services/modules which can then be launched directly from this window.

Accessing This Window/Screen

To access this window:

1.    Start the OpenLink Central Console.

2.    Select Launch Available Services from the menu.

The following window displays in V10.1R1 and later:

Fields

This window contains the following fields:

Field

Description

Service Group Filter

Select a filter to limit the services shown in the Available Services panel to those related to the selected filter(s).

Filter Service

Searches within the Available Services listing for a search string entered in the field.

This field is available in V8.1r1 and up.

A list of the services in the system available for launching

When selected, the Launch Available Services window will close after launching the service.

This field is available in V12.1 and above.

Allows the user to select into which presentation module the AFE service will be launched.

This field is available in V10.0R1 and above.

Launching a Service

To launch a service:

1.    Select a service group or groups in the Service Group Filter to filter the services shown in the Available Services listing.

2.    Highlight the service in the Available Services listing.

3.    Click the Launch button to start the service.
