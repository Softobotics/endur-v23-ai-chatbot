System Monitor - database – analyze table statistics

Overview

This window shows database object details and provides the ability to perform an update of database statistics.

 

The following Security Privileges are applicable to this window:

Privilege ID

Privilege

Functionality

29600

Access Database Tab

Allows access to the Database tab and some associated sub-tabs.

29610

Access Table Statistics Tab

Allows access to this particular tab.

29260

Update Table Statistics

Allows access to the functionality to update table statistics.

 

 

This tab is available in v8.0r1 and up only.

 

See System Monitor

 

Accessing This Window/Screen

To access this window:

  1. Start the OpenLink System.
  2. From OpenLink central, click the System Monitor icon
  3. Select the Database tab.
  4. Select the Analyze Table Statistics sub-tab.

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

 

Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.

 

Buttons

This window contains the same toolbar buttons as the System Monitor. This tab includes the following buttons:

Button

Description

Select a table and click this button to recalculate the table statistics shown in the data table.

Reloads the system table data in the table.

 

Fields

This window contains the following fields:

Variable

Description

Owner

The name of the schema owner that owns the objects.

Object Name

The name of the selected application table.

Last Analyzed

The calendar date and time the selected table statistics were updated.

Tablespace Name

The logical storage area of the table.

Rows

The number of rows contained in the selected table.

Avg Row Length

The calculated average row length for the selected table.

Blocks

How many blocks the selected table occupies.

Cached

Indicates if the data in the selected table is loaded into server memory.

Logging

When set to “S”, the information written or removed from the table will be logged.

Monitoring

Indicates if the selected table is being monitored, meaning, all table changes are being noted.

 

Column Header Menu
