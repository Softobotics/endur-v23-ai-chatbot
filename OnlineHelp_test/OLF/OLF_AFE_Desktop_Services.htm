AFE Desktop Services

Overview

AFE (Adaptive Front-End) Desktop Services enables the creation of OpenLink Central work environments that are relevant to users and their responsibilities employing filtered pick lists, based on keywords, to customize desktop access.

AFE Desktop Services support is available in versions 80R2 and later.

Setting Up AFE Desktop Services

Setting up AFE Desktop Services is a two step process:

  • Create Desktops
  • Configure OpenLink Central.

Create Desktops

Use the OpenLink Desktop Builder to configure the desktops required for the environment. The example in the illustration above shows three different desktops for the processing of Options – “Options1, Options2 and Options3”. Note that the prefix, “Option”, for these related desktops must be the same to display in the selection list.

Configure OpenLink Central

1.    Create Desktops required for the User base using OpenLink Desktop Builder.

2.    Create Tabs using the Openlink Configurations window if services should logically be segregated from the OpenLink main tab.

3.    Create and Configure Button(s) using the Openlink Configurations window, using “OpenLink Desktop” as the Selected Service. Customize the “OpenLink Desktop” service by supplying Keyword Arguments via the Service Arguments window.

4.    Save the OpenLink Central Configuration from OpenLink Central.

Create and Configure Button

Create and configure an Option Desktops button to accommodate the “Option” keyword based pick list.

From the OpenLink Central Configuration window, Button Configuration tab,

  1. Select “Custom Services” from the Tab Name pick list.
  2. Highlight “OpenLink Desktop” form Available Services and activate it as a Selected Service.
  3. Supply “Option Desktops” as the Button Caption and Tool Tip Text.
  4. Select the Options icon.
  5. Select “String Keywords” from the Service Selection pick list and click the Args button.
  6. Specify “Option” as the keyword “Value” and click OK.

  1. Click OK to save the button configuration.
