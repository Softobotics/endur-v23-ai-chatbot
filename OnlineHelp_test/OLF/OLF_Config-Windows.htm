ConfigURATION

Overview

The Configuration window allows users to customize the columns in a table or listbox. This is accessible from most screens in the system that contains a listbox, such as Profile, Resets, Fees, Cash Flow, and so forth. It presents users with a complete list of columns for a specific screen, which the user may hide or display.  The user also has the option of assigning aliases to these columns and creating duplicates of these columns.

 

Accessing This Window/Screen

This window is accessed from various functionalities in the system. For illustration purposes, the following is an example of how it is accessed:

Menu Items

This window contains the following menu items:

Menu

Item

Description

File

Load

Opens the Load window. This window allows the user to select a saved configuration to load on screen.

 

Save

Saves the configuration currently loaded on screen.

 

Save As

Opens the Save As window. This window allows the user to save the configuration under another name.

 

Set Default

Opens the Set Default window. This window displays a list of saved configurations. Put a checkmark in the “Default” field to set the configuration as the default configuration. For the new settings or default to take place, close and reopen the window.

 

Delete

Opens the Delete window. This window allows the user to delete a selected configuration.

 

Use Defaults

Restores the system default configuration.

 

Apply

Applies the new settings and closes the window. If this option is selected, the user does not need to close or reopen the configured window for the change to take effect.

 

Exit

Closes the window.

Help

Help

Displays the system Help files.

 

Buttons

This window contains the following buttons:

Field

Description

Search

Performs a column search in the “Available” listing based on the keyword entered in the “Search Column Name” field. Click this button again to go to the next match in the “Available” listing.

Duplicate Field

Creates a copy of a selected field.  To duplicate a column or list of columns already selected, highlight the rows to copy and this button.  The copied version will be inserted below the last selected row.

Adds a highlighted item in the “Available” listing to the “Selected” listing. More than 1 item may be selected for transfer.

Removes a highlighted item from the “Selected” listing.

Moves the highlighted item in the “Selected” listing 1 row up the list per click of this button.

Moves the highlighted item in the “Selected” listing 1 row down the list per click of this button.

 

Fields

This window contains the following fields:

Field

Description

Search Column Name

Input field to enter the search keyword.

Available

Group

The group in which the column belongs. The group is system-assigned and is used to group columns (fields) that are mapped to the same table or group of tables.

To sort and further filter the list, right click the column header to display the Column Header Menu.

Column

The name of the column. The list of available columns depend on the listbox that is being configured.

To sort and further filter the list, right click the column header to display the Column Header Menu.

Selected

Group

The name of the group in which the column belongs.

Column

The name of the selected column.

Column Title

The name of the selected column as it appears in the column heading. This field may be edited.
