# Payment date offsets

## Overview

The 
	 following describes the possible values for the Payment Date Offset 
	 field.  Note that this field defaults to a valid value.  The 
	 default value is different depending on the type of deal.  The 
	 default value is typically appropriate for market convention, but 
	 clients may need to override it.  The actual payment dates 
	 that get generated by the Payment Date Offset can be see on the profile 
	 screen.

	 Profile
