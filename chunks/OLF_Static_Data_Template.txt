# Static Data Template

## Overview

The Static Data Template is used throughout the system by several functions to add and maintain static data. This window may have different buttons and fields, depending on the context from which it is being displayed. Note that only user-defined data can be maintained or deleted.

The functionalities that utilize this window are as follows:

- §  Static Data – Except for the ANE Configuration and Credit Derivative Setup windows, all static data utilizes this template.
- §  Extension Security
See Also

The User Data Worksheet module provides a graphical interface for managing User Table data with additional levels of control. The end-user screen mirrors the System’s Static Data screen, while the data view is controlled by custom scripts.

## Accessing This Window/Screen

There are various ways to access this window. To illustrate:

1. Start the Admin Manager.
1. Select the General Administration tab.
1. Select the Static Data icon to launch the Static Data window.
1. Scroll to and select a static data table. In this example, “ABS Pool Asset Type” was selected.
1. Click the Edit button.
1. The following window displays:
![](OLF_Static_Data_Template_files/image001.jpg)

### Buttons

The buttons may vary depending upon the functionality to which the static data applies.

### Fields

The fields that display may vary depending upon the functionality to which the static data applies.

### Column Header Menu

The Column Header Menu displays if any column header of a table is right-clicked. Use this menu to modify the table configuration.

## Sorting Data

Double-click the header of the column by which the table will be sorted.

## Adding Data

To add data:

1. Click the Add Row button or EditàAdd Row to enable a new entry row in the table.
1. Enter data in the appropriate fields.
1. Repeat these steps to add more data.
1. Click the Save button or select FileàSave. The system assigns a unique, system ID number to each new data row.
## Editing Data

To edit data:

1. Edit data in the listing.
1. Click the Save button or select FileàSave.
## Deleting Data

To delete data:

1. Highlight the row(s) to be removed. To select all rows, select Edit à Select All from the menu.
1. Click the Delete button or EditàDelete Row.
1. Click the Save button or select FileàSave.
