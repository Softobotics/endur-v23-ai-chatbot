# Crystal Report Viewer

## Overview

After a Crystal Report has been designed and executed, the results can be saved within the database.  This function allows the user to view previously saved Crystal Report results.

Crystal Reports can be accessed from the Crystal Reports window and directly from the Trading Manager.

See Crystal Reports
