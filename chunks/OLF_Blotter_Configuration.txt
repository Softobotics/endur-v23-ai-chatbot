# BLOTTER CONFIGURATION

## Overview

The Blotter Configuration window allows users to specify the columns to display in a table or blotter. An example of this blotter is the Agreement/Provision Listing window.

## Accessing This Window/Screen

This window is accessed from various functionalities in the system. For illustration purposes, the following is an example of how it is accessed:

1. Start the Trading Manager.
1. Open the Swap deal input window.
1. Select View à Agreements. The Agreement/Provision Listing window.
1. Select Configure à Configure Listing.
1. The following window displays:
![image002](OLF_Blotter_Configuration_files/image001.jpg)

### Menu Items

None.
