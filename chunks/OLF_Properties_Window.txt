# PROPERTIES WINDOW

## Overview

The Properties Window allows users to set and save the location and security privileges for a file such as a plug-in/script, task, screen configuration, query, etc.

## Accessing This Window/Screen

This window may be accessed from various parts of the system. For illustration purposes, the following steps are provided:

1.    Start the Trading Desktop Explorer or Trading Manager.

2.    Open any deal input window.

3.    Click the Pricer icon.  The Pricer window of the instrument displays.

4.    Click the Quick Simulation icon.  The Simulation Results viewer displays.

5.    Click the Export to Script icon.

## Setting the Property of a File

Follow the steps below to set the property of a file:

1.    Enter the name of the file in the “Name” field.

2.    Select the location and define the privileges of the user, security group, or all users for the particular file.

3.    Click the Save button to save settings. If the name of the file already exists, a message will display if the existing file will be overwritten. To save the file as another file, enter a different name for the file.
