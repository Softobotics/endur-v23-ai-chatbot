# JBO Project Manager

## Overview

The Plugin Project Manager (formerly JBO Project Manager) screen allows the user to add new or delete existing OpenJVS plugin project names. In addition, the user can assign other project references to a project and also search on project references by name.

## Accessing This Window/Screen

V8.2r1 and up:

1.    Select the System Administration tab from Admin Manager.

2.    Select the Plugin Editor icon.

3.    Select Tools → Project Manager.

The following window appears:

![image002.jpg](OLF_JBO_Project_Manager_files/image001.jpg)

V8.0r1 to v81.r2:

1.    From OpenLink Central, launch the JBO Bulk Import service.

2.    Select File à New Project.

The following window appears:

![image002](OLF_JBO_Project_Manager_files/image002.jpg)
