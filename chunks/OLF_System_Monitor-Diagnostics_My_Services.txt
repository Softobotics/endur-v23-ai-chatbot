# SYSTEM MONITOR – Diagnostics – my services

## Overview

This window contains a display only view of service details for the current user. The components viewed in this window have been previously configured in the Services Manager module.

Access to this window is controlled by Security Privilege #29300, Access Diagnostics Tab.

This tab is available in V8.0r1 and up.

See System Monitor

## Accessing This Window/Screen

To access this window:

![image008](OLF_System_Monitor-Diagnostics_My_Services_files/image001.jpg)

The following screen displays:

![image002](OLF_System_Monitor-Diagnostics_My_Services_files/image002.jpg)

Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

### Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.
