# APM Integration Utility

NOTE:  This is a separately 
 licensed feature. Please contact your account manager for additional information 
 and reference documents.

## Overview

The APM Integration utility is facilitates the generation 
 of SQL integration files required for integrating simulation results as 
 APM packages. This tool targets Professional Services, Consultants, Internal 
 OL Market teams, and developers.

## APM Package Design

APM can join various results together and enrich dimension 
 data to supported calculated results. As a result, it is best practice 
 to separate the dimension data from the measure data into separate simulation 
 results so that the dimension data can be reused among all the other results 
 with minimal processing time.

#### Identify the desired data to display within APM

Determine if the data is considered dimension or measure 
 data:

It is dimension data if 
 it is an attribute or property of a deal or nom and does not require any 
 calculation. If it can be queried via the database, it is dimension data. 
 The data will have a data type of Integer or String. It will not have 
 any Double data types. It generally completes quickly.

Example of Dimension data: APM Deal Information / 
 Deal Attributes:

It is measure data if it 
 requires a simulation to calculate the value. For example, delta, daily 
 volumes. The data will have a data type of Double. It generally takes 
 the longest amount of time to generate.

Example of Measure data: APM Delta / Greeks – Delta

After a simulation result is created and ready to 
 be integrated into APM, the next step is to run the utility.

 and launching it requires a security privilege.
