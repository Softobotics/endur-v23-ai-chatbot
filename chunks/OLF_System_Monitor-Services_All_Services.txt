# System Monitor - Services - All Services

## Overview

The All Services tab provides an overview of all System services. This window provides a high-level overview of domain services, grid and Connex services and workflow management. This window intends to provide a quick status view of all configured system services.

Access to this window is controlled by Security Privilege #29200, Access Services Tab.
