# Date and Time Period Format Conventions

## Overview

The OLF system accepts date information in several different formats.  The user can enter a specific date in a variety of different configurations, as shown below.  The user can also enter date information using “symbolic dates.”  This is a shorthand in the OLF system for different time periods and different dates.

Dates

The system accepts dates in the following formats:

## Time Periods

For some date fields, the system allows you to define the date by entering a relative offset rather than a specific date.

For example, if you enter 5y in the Maturity Date field on a deal entry window, the system calculates the maturity date to be 5 years from the start date.  Some fields require a relative offset.  In either case, when entering relative offsets in the system, enter a number followed by the letter d for days, w for weeks, m for months, and y for years.  The system incorporates good business day logic when using relative offsets to calculate future dates.
