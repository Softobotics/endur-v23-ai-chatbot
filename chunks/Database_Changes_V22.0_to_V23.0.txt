### The following columns have been added:

These columns were added to support new functionality. Therefore they 
 should not affect clients who are upgrading. One way they might affect 
 clients is if a client used a “*” for a "What" clause in an 
 SQL statement. When they upgrade, they would get an additional column 
 or columns, which may cause issues in custom plug-ins/scripts. We recommend 
 that clients use specific what clauses rather than the general “*” to 
 prevent this from happening.

For more details about these columns, see the AdHoc Query Viewer and/or 
 the Data Model Documentation for more details.

See AdHoc 
 Query Viewer
