# Symbolic Dates

## Overview

Symbolic dates can be entered into most of the fields in the system 
	 that hold dates.  For example, the Start Date and End date 
	 of the deal.  For each different date field, there may be 
	 a different date origin.  For example, the date origin for 
	 the End Date of a deal is typically the start date of the deal.  So 
	 typing in a symbolic date into the End Date field of 0d (zero days 
	 from origin) would set the End Date to be equal to the Start Date 
	 that has been entered.

When a user enters a symbolic date into a date field, the value 
	 that would actually be displayed would be the real date.  The 
	 date format is based on the user’s preferences. For most deal input 
	 screens, you can hit the F1 key to see what the symbolic dates that 
	 were entered are (in a window that pops up).  This is useful 
	 for verifying templates are set up correctly.

Symbolic dates typically produce good business day (GBD) results. 
	 The only symbolic dates that can fall on a holiday or a weekend are 
	 numbers “1” to “31,” “cd,” and “fom.”
