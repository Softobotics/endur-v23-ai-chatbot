# OpenLink Central Control Panel

## Overview

The OpenLink Central Control Panel serves as a primary access point to the system. The OpenLink Central Control Panel can be configured by the system administrator/user with the proper security privileges enabled.

Configuration changes to the OpenLink Central Control Panel or the OpenLink Desktop - OpenLink Central Sidebar (for example, tabs, groups, and services) are kept in sync with each other. The sidebar is available in V91r2 and up.

AFE Services (Adaptive Front End Services) facilitate configuration of OpenLink Central as a process to open screens and services directly without first opening the parent functions. This process can take arguments at startup and launch the requested AFE Services. Once the service is started, it can remain in the background listening for further requests.

The following security privileges are applicable to configuration of the OpenLink Central Console. The appropriate privileges must be enabled to provide the administrator/user proper access to configuration functionality.

### Environment Variable

The environment variable AB_SHUTDOWN_APP_FROM_MASTER_CENTRAL controls whether closing OpenLink Central closes the system or not. Setting the variable to False (the default value) causes the system to shut down when the last remaining application screen is closed. When this variable is set to True, closing OpenLink Central will shut down the system.

### Accessing the Control Panel

Typically, this window is automatically launched with the initialization of the system. The system allows for the Control Panel to be closed while other services or managers are in use. To access this window after it has been closed but while the system is still in use:

1.    Locate the Launch Available Services menu item or icon  in a service or manager window.

2.    Locate OpenLink Central in the list of services.

3.    Launch the console.

## OpenLink Central Console Modes

The OpenLink Central Console can be displayed in three different modes: Full, Standard and Compact. Full Mode includes the Menu Bar, Tabs/Buttons, and the Title Bar. Standard Mode, the default mode when OpenLink Central is launched, does not contain the Menu Bar. Compact Mode only displays the Title Bar.

## OpenLink Central Control Panel Sections

The console is comprised of four sections: the Title Bar, the Menu Bar, the System Managers tab(s), and the System Utilities (“Favorites”) bar. Each of these sections is described below.

·         Title Bar – Displays the system code version, the server, the database, and the user logged into the system.

·         Menu Bar – Displays only if OpenLink Central is in “Full Mode.” The menu allows the user to set up or modify the configuration of OpenLink Central. If this is hidden, right-click on the Title Bar to display the menu.

·         System Managers Tab – Displays the OpenLink Tab by default. This tab contains the System Managers. The buttons are active only if the user has access to the respective modules. This may contain other tabs defined by the user. To activate another tab, click the tab or select the tab from the Available Tabs menu. Move the horizontal scroll bar located below the buttons to scroll through the tab.

·         System Utilities Bar – Contains the System Utilities.
