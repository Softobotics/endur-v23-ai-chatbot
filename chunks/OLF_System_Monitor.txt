# System Monitor

## Overview

The System Monitor provides up-to-date status information on the underlying services, engines & technical infrastructure. This tool, intended for use by Information Technology professionals, is used to diagnose running engines/services and serve as a central source of information for the selected user to perform system health checks. In addition, it supplies low-level diagnostic views of messaging, licensing, toolkits, databases and underlying binary configuration.

## Accessing This Window/Screen

To access this window:

1.    Start the OpenLink System.

2.    From OpenLink Central, click the System Monitor icon .

The following screen displays:

![image012.jpg](OLF_System_Monitor_files/image002.jpg)

### Other Ways to Access this Window

From OpenLink Central and from the main window of each manager (Admin Manager, Trading Manager, etc.), the keystroke combination Ctrl+F4 will activate the System Monitor. The Script Engines tab is disabled when this window is not run from OpenLink Central. Separate instances can be run from each manager.
