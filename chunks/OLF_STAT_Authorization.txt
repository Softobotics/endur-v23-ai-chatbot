The Scenario Test Automation Tool functionality 
 is an optional component of the Unit Test Runner module. The Scenario Test Authorization Mapping 
 screen defines which test users are allowed to switch to other test users 
 during ActivityAs actions.  This screen is protected by several 
 security privileges.  It is only accessible when security 
 privilege 2002202 – “Access Scenario Test Authorization Mappings” is enabled.

## Accessing this Window

Note:   There are multiple 
 ways to access this window; however, only one way is defined because some 
 features can only be accessed via this procedure.

1.      From 
 OpenLink Central, right-click anywhere on the header and select Launch 
 Available Services. The Launch Available Services window displays.

2.      Type 
 Scenario Test Authorization Mapping 
 in the Filter Service field, 
 highlight Scenario Test Authorization 
 Mapping in the Available Services panel, and then click 
 Launch. The following window 
 displays:
