# System Monitor - Domain Services Monitor

## Overview

The System Monitor – Services tabs work with the Services Manager module. Many of the components viewed in this tab have been previously configured in the Services Manager.

The Domain Services Monitor (formerly known as Domain Grid Monitor) shows details of processes, functionality and information related to OpenLink’s Services and Grid Functionality. It provides management facilities around domain grid configuration in addition to displaying running services that may or may not take advantage of the domain grid.

This tab is only available in V8.0r1 and up.

Access to this window is controlled by Security Privilege #29250, Access Domain Grid Monitor Tab.

### Views

There are three views available on this tab controlled by radio buttons. The Grid Monitor and Request Monitor buttons provide the same view those described under the Services Manager. The Request Monitor is applicable to v91r2 and later. The Running Services view is detailed on this page.

## Accessing This Window/Screen

To access this window:

1.    Start the OpenLink System.

2.    From OpenLink Central, click the System Monitor icon .

3.    Select the Services tab.

4.    Select the Domain Services Monitor (Domain Grid Monitor in v80r2 and earlier) sub-tab.

The Running Services View displays by default:

![image012.jpg](OLF_System_Monitor-Services_Domain_Grid_Mon_files/image002.jpg)

### Other Ways to Access This Window/Screen

The module may also be launched as a service. From OpenLink Central, navigate the menu icon and select Launch Available Services. Select System Monitor from the list box.

### Menu Items

This window contains the same menu items as the System Monitor. Menu item availability depends upon the tab being accessed.
