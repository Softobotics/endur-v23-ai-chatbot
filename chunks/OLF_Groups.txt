# Groups

## Overview

The Groups window allows the user to create new, rename, and 
 delete existing groups in a window. This screen is used by the several 
 functionalities in the system such as Portfolio Groups and Entity Groups.

See also:

Portfolio 
 Groups

Entity 
 Groups

## Accessing This Window/Screen

This window is accessed from several functionalities 
 in the system. To illustrate how it is accessed:

1. Start 
 the Admin Central Sidebar.
1. If not 
 yet selected, click the General Administration tab.
1. Click 
 the Portfolio Groups icon .
1. Select 
 Groups à Setup 
 Groups

## How To: Adding a New Group

1. Click 
 the Select Group button and select “ADD NEW GROUP” from the pick 
 list. The “Group Name” field clears.
1. Input 
 the name of the new group in the Group 
 Name field.
1. Click 
 the OK button to save the new group. The window closes and the 
 new group column is added to the Portfolio/Entity Groups window.
## How To: Deleting an Existing Group

To delete an existing group:

1. Click 
 the Select Group button and select the group to delete from the 
 picklist. The group’s name displays on the “Group Name” field.
1. To 
 check the items that belong to the group prior to deletion, click the 
 List <Items> In Group button. The list displays all the items 
 defined for the particular group.
1. Click 
 the Delete Group button to delete the group. Note that items are 
 not deleted when groups are deleted.
1. Click 
 the OK button to save changes. The window closes and the column 
 of the group is removed from the Portfolio/Entity Groups window.
## How To: Renaming an Existing Group

To rename an existing group:

1. Click 
 the Select Group button and select the group to rename from the 
 pick list. The group’s name displays on the “Group Name” field.
1. Edit 
 the name of the group.
1. Click 
 the OK button to save the modification.
