# TOOLBAR AREA CONFIGURATION MENU

## Overview

The Toolbar Area Configuration Menu allows the user to change the configuration of the toolbar, e.g., create, hide, or display toolbar panels; modify the configuration of toolbar icons; and add or remove icons from a toolbar panel.

This functionality is available in V8.0r1 and up.

## Accessing This Window/Screen

This menu can be accessed from various windows of the system that has a toolbar. To access the menu, right-click any area of the toolbar. For illustration purposes, the following is an example of how it is accessed from the Settlement Desktop:

1. Start the Operations Manager.
1. Click the Settlement Desktop icon. The Settlement Desktop window displays.
1. Right-click on any area of the toolbar.
1. The following menu displays:
![image002](OLF_Toolbar_Area_Config_Menu_files/image001.jpg)
