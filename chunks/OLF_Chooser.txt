# CHOOSER DIALOG BOX

## Overview

The chooser dialog box is used throughout the system. It is used to select items from a list. It can contain many different types of data but is always used the same way.

Regardless of the type of data used, the principle remains the same:

## Adding Items To The Right Side Column

## Removing Items From The Right Side Column

Alternately, you can double-click on any item to move it from one side to another.

If an item is in the Selected column, it will be included in the system’s processing
If an item is in the Available column, it will not be included in system processing but can be added

Open Admin Manager.
The General Administration tab displays.
Click the Auto Document Release icon.

Open Admin Manager.
The General Administration tab displays.
Click the Static Data icon.

Select System Pick List and click the Edit button.
Select Instruments and click the Edit button.
The following screen displays:

Select the items in the left side column to be added.
Click the Add button, or click Add All to add all items in the left side column.
Click OK.

Select the items in the Right Side column to be removed.
Click the Remove button, or click Remove All to remove all items in the Right Side column.
Click OK.
