# How To Query by Multiple Toolsets

In this example, create a query to search for 
	 all ComSwap or Swap deals. By choosing two toolsets, 
	 we are making an “or” conditional. An “or” conditional 
	 indicates that the user made multiple selections in a single row.

The following example brings back Swap
or ComSwap transactions with a status of Validated.

To run a query:

1.      Click 
	 the Query icon  
	 from the menu. The Trades Query window displays with a previously-saved 
	 query view.

2.      Click 
	 the New Query icon , or select 
	 FileàNew Query 
	 from the main menu.

3.      Ensure 
	 Transaction is displayed in the Query View field located 
	 at the top right-hand side of the panel. This is because the selections 
	 for this query are located in the Transaction table.

![](How_to_Query_by_Multiple_Toolsets_files/image007.jpg)

4.      Go 
	 to the ToolSet field and right-click in the Selected Values 
	 column to display the pick list. Select Swaps and ComSwap, 
	 and then click the OK button.

![](How_to_Query_by_Multiple_Toolsets_files/image008.jpg)

Hover over the ToolSet field to 
	 see the snippet that indicates that the system sees this as an “or” 
	 conditional.

![](How_to_Query_by_Multiple_Toolsets_files/image009.jpg)

5.      Execute 
	 the query by clicking the Execute and Close button. The query 
	 results display.
