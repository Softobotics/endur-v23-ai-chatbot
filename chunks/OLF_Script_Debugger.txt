# Script Debugger

## Overview

The Script Debugger is a helpful tool that users can run when they encounter run time errors or erroneous data results.  It allows users to set “break points” in the scripts at which to stop.  The user can then step through lines of code examining variables and tables, to try and find what caused the error.

## <sdbg> Shell

The shell "terminal" is the lower text area in the sdbg window.

Type help at a <sdbg> prompt.  A list of sdbg commands, including print, breakpoint, continue, step, finish, skip, set, and help displays.

Note:  Print [variable] should be print [expression].  An expression can be of any form acceptable in a script, such as x * (y+3), 10*growth(rate, dcf) , and so on.

Abbreviation:  When a command is typed, its prefix can be used as long as this prefix does not confuse another command above it in this list e.g., use 's' for step, 'sk' for 'skip', and 'se' for set.

Command history is supported.  You can either move the cursor back to a previous command and hit RETURN/ENTER, or, use M-P, M-N to navigate along command history.

Open the Trading Manager.
Right-click on the Abort Task button and select “Debugger.”
Select a task from the picklist that appears.
Click on the Load Task button.
The Script Debugger screen displays with the AVS script for the task that was selected.

Open a script using the AVS Script Editor.
Add the line #SDBG to the very first line of code and recompile it. 
When you next run your task it will stop execution of your code at the very first line and pop up a Debugger Window.
This allows you to step through your code and set breakpoints, etc.
