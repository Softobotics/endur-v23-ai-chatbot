# Add Formula Column

## Overview

The Add Formula Column window allows users to create and maintain formula columns. This screen is included in most table viewer instances in the system, which can be standalone or embedded as a panel in a screen.

See:

Table Viewer

Configure View

## Accessing This Window/Screen

This window is accessed from various functionalities of the system. For illustration purposes, the following are examples of how it is accessed:

1. Start an OpenLink Desktop.
1. Right-click a column header.
1. Select Configure à Formulas à Add Formula Column.
or,

1. Start the Trading Manager.
1. Select View à Transaction Field Viewer. The Transaction Field Data window displays.
1. Select Configure à Configure. The Configure View window displays.
1. Select Formulas à Add Formula Column.
The following window displays:

## Defining a New Formula Column

To define a new formula column,

1. Enter the formula in the unlabeled text field by inputting or clicking the desired function, parameters, and operators to insert in the formula.
1. Enter the name, title, and data type of the new column.
1. Click the Apply button.
Important:

Only Integers will be used for querying the data. All column values are returned as double and not String Values. The Ad-hoc table viewer should be used to determine integer values for items such as ins type, buy_sell etc.
