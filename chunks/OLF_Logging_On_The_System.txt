# LOGGING ON TO THE SYSTEM

## Overview

The Logon window is the screen that initially displays when the system is accessed. Users must enter their designated user name and password to gain access to the system. The Title Bar indicates which major release the system is running.

![image001](OLF_Logging_On_The_System_files/image001.jpg)

### Lower Panel

This panel displays when the toggle  is clicked.

![image003](OLF_Logging_On_The_System_files/image003.jpg)

## Logging On to the System

To log on to the system:

1.    When the system is started, the Logon window displays.

2.    Enter user name and password in the User Name and Password fields, respectively.

3.    Click the OK button. The OpenLink Central Control Panel displays.

## Changing the Password

To change the user password:

Enter user name and password on the User Name and Password fields, respectively.
Open the lower panel of the Logon window.
Select the Change Password option.
Click the OK button. A window displays prompting the user to input the old and new the passwords.
Click the OK button to confirm change.
