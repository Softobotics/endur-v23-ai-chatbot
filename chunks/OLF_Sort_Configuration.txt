# SORT CONFIGURATION

## Overview

The Sort Configuration window allows users to specify how the items in a table will be sorted and listed.

## Accessing This Window/Screen

To access this window:

1. Start the Trading Manager.
1. Open the Bond Transaction Screen.
1. Select the Input option.
1. Click the Sorting button.
1. The following window displays:
![image003](OLF_Sort_Configuration_files/image001.jpg)
