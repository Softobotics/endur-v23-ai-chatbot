# LINK SCREEN CONFIG DEFINITIONS

## Overview

The Link Screen Config Definitions window allows users to define the following:

·         Default deal entry screen configuration for a toolset, instrument type, or template for users and interface groups

·         Default OpenLink Central configuration for users and interface groups

·         Default Presentation Module configuration for users and interface groups (available in V9.0R1 and above)

## Accessing This Window/Screen

To access this window:

1.    Start OpenLink Central.

2.    Select OpenLink CentralàEdit Configuration Links from the menu.

The following window displays:

![](OLF_Link_Screen_Config_Definitions_files/image001.jpg)

### Other Ways to Access This Window

1.    Launch the Admin Manager.

2.    From the General Administration tab, select the Link Screen Configuration Definitions icon .
