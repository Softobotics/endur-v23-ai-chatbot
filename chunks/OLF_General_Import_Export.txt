# General Import/Export

## Overview

The General Import/Export window is used to import/export a variety of system data/definitions from/to .CSV or XML formats. This window is used for import/export in many areas of the system. Examples are listed below. This window allows the user to invoke general importing and exporting functions, as well as setting up the definition to be used. It may or may not contain different parameters that may be needed to correctly import/export data. While window titles may vary, the design and functionality are the same.

This window is used to import/export the following:

·         Historical Prices/Hourly Historical Prices – Uses Index Name and Price Type as parameters

·         Curve Adjustment – Uses the Adjustment Definition Name as parameter

·         Static Data – The static data being imported/ exported is used as parameter

·         Time Zones – Uses TimeZone Label as parameter

·         Products – Uses Product Type and Name as parameters

·         Bond Futures Conversion Factors – Uses the Instrument Number as parameters

·         Settlement Desktop Definition – Refer to Settlement Desktop for the description of the parameters

·         Market Volatility Definitions - v10.0r2 and up.

### Importing Data

1. From the General Import/Export tab, select the format of the file to import on the “Format” field.
1. To change the default location of the import file, enter the location of the file to import on the “Filename” field. To browse for the file, click the Browse button. A file browser displays allowing the user to select the location of the file to import.
1. To view the file to import, click the View Import File… button. A spreadsheet/browser displays showing details of the import file.
1. Click the Import button to import data. If import is complete, the message “Import successfully completed.” displays.
1. Click the OK button. The holiday schedule is added to the Holiday Schedules list.
### Exporting Data

1. From the General Import/Export tab, select the values of the parameter/s that will be exported. For example, to export historical prices, select the index and the price type that will be exported.
1. Select the format of the file will be saved as in the “Format” field.
1. To change the default location of the export file, enter the path and name of the file where data will be saved in the “Filename” field. To browse for the file, click the Browse button. A file browser displays allowing the user to select the location and name of the export file.
1. Click the Export button to export data. If export is complete, the message “Export successfully completed.” displays.
1. Click the OK button.
1. To view the file to export, click the View Export File… button.

·         Select a new default definition

·         Execute a definition that is not the default

·         Edit an existing definition

·         Create a new definition

### Selecting a Default Import/Export Definition

1. Select the Definitions tab.
1. Put a check mark (by clicking) on the Default field of the definition that will be set as the default import/export definition.
1. Click the Save Defaults button to save modifications.
### Running an Import/Export Definition (that is not the Default)

1. Select the Definitions tab.
1. Highlight the row that will be executed.
1. Click the Import or Export button to execute the definition.
