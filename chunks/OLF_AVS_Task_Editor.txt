# Task Editor

## Overview

To run a plugin, a task must first be created.  The task schedules plugins to run at specific times or specific intervals.  Using the Components feature, specific plugins are assigned as components of a task.  This is the blueprint and tells the task what type and what plugin name to run.  Tasks can be defined within the Trading, Credit, or Risk Managers or through the Script button of the Operation Manager. Scripts can be imported (through Operations Manager à Script) before assigning them to tasks.

Note: This page is for v90r1 and later. For v82r1 and earlier, see AVS Task Editor.

Note: Plugins were formerly known as Scripts and as AVS Scripts.

## Accessing This Window/Screen

A Task can be defined multiple ways in the system.  This procedure is just one example of how to access this window.

1.    Start the Trading Manager.  The Trading Manager browser window displays.

2.    Select Script à Task Editor.

## Creating a Task

To create a Task:

Note:  Access the Task Editor window through any appropriate Manager.

Note:  A description might describe what this task does, or it may describe how often the task should be executed.

## Task Permissions

For more information on task properties, see the section on Task Permissions.

Click the “Task Name” field and enter a name for the task in the Task Editor window.

Select the “Description” field and enter a description if applicable.

Enter the name of the Param Plugin that should be executed as part of this task.  This field is optional.
Enter the name of the Main Plugin that should be executed as part of this task.  This field is optional.
Enter the name of the Page Viewer Plugin that should be executed as part of this task.  This field is optional.
Enter the name of the Output Plugin that should be executed as part of this task.  This field is optional.
Select the appropriate parameters in the fields of the Task Scheduling panel.
Press the Save button or select File à Save to Database.
Select File à New to clear the Task Editor window.
Repeat Steps 1 through 8 to assign the rest of the plugins to tasks.
