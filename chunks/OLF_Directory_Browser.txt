# DIrectory Browser

## Overview

The Directory Browser allows users and administrators to easily find and administer files in the OLF virtual file system. It displays a list of existing directories, scripts, tasks, stored queries, etc. The primary goal of this screen is to provide a single place to find, open to modify, and save a task, script, query, etc.

See:

AVS Task Editor

Query Manager

Other Directory Browser screens:

Open Query From Directory Browser

## Accessing This Window/Screen

This window may be accessed from various functionalities of the system. For illustration purposes, the following is an example of how it is accessed:

1. Start the OpenLink Central.
1. Click the Directory Manager icon .
1. The following window displays:
![image004](OLF_Directory_Browser_files/image002.jpg)

### Other Ways to Access This Window/Screen

**Option 1:**

1. Start the Trading Manager.
1. Select File Query. The Trading Query window displays.
1. Click the Triangle button located at the bottom left corner of the screen. The lower panel of the window displays.
1. Right-click the “AVS Script” field.

## Restricted Directories

Certain directories in the OLF system are restricted. That is, even an Administrator does not have “write” access to the files in them.  These “restricted” directories are labeled “OLF_Customer” and “OLF_Standard.”

The “OLF_Customer” directory contains scripts/tasks created specifically for the customer for whom it is running.  The “OLF_Standard” directory contains system-standard files that should not be edited.  However, the Administrator will have permission to open the files from those directories, then edit and save them in a separate directory.  The default adds the word “copy” at the end of a file name.

## Editing Scripts/Tasks/Queries/etc. From the View by File Tab

To edit scripts, tasks, queries, etc. from the View by File tab,

1. To facilitate the search, sort the table by your search key. For example, if you are searching by name, sort the table by name.
1. To sort by the search key, double-click the column header of the search key, e.g., if searching by name, double-click the “Name” column header.
1. Double-click the row to edit. The applicable screen of the file displays.
Note: Another way to open the file is to highlight the row and click the Select button.

1. Edit and save the file.
## Editing Scripts/Tasks/Queries/etc. From the View by Category Tab

To edit scripts, tasks, queries, etc. from the View by Category tab,

1. From the left table, click the category of the file to search. The files of the selected category displays in the File Listing table (i.e., table located at the right side of the screen).
1. Double-click the row to edit in the File Listing table. The applicable screen of the file displays.
Note: Another way to open the file is to highlight the row and click the Select button.

1. Edit and save the file.
## Editing Scripts/Tasks/Queries/etc. From the View by Directory Tab

To edit scripts, tasks, queries, etc. from the View by Directory tab,

1. From the Directories table, click the folder (i.e., directory) to search. The files of the selected directory displays in the Contents of Directory table.
1. To display only the files of a particular category, select the category in the “File Type” field. This field defaults to “All” so all files contained the selected directory display.
1. Double-click the row to edit in the Contents of Directory table. The applicable screen of the file displays.
Note: Another way to open the file is to highlight the row and click the Select button.

1. Edit and save the file.
