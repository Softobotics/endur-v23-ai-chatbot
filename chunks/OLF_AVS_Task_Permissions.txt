# Task Properties

## Overview

Each Task has permissions associated with it.  The person who creates a script is the owner.  The owner can associate Read, Write, and Execute Permissions to the script for himself, to a security group, and to the public.

Note: This page is for v90r1 and later. For v82r1 and earlier, see AVS Task Properties.

## Accessing This Window/Screen

This window can be accessed by following the steps below.

1.    Start the Trading Manager.

2.    Select Script à Task Editor.  The Task Editor window displays.

3.    Select File àOpen.  A pop up list of available tasks in the database displays.

4.    Select File à Properties.

The following window displays:

![image010.jpg](OLF_AVS_Task_Permissions_files/image001.jpg)

Note:  The settings in this window are the System-upgrade defaults for existing Tasks.  The Owner and Group information and Owner/Group/Public permissions can be modified. However, it is also important to note that only one security group can be assigned to each task (when one group is assigned the privilege, any previously assigned group will lose the privilege).

## Assigning Access Rights for a Task to Security Groups

The owner of a task has the rights to assign the rights to access this task to one security group in the system.  For example, a task that is relevant to the job functions of back office personnel can be restricted to that group. Each time the Task is assigned to a group and saved, the previous definition is overwritten.

IMPORTANT:  If no group is assigned to a Task, it means that ALL users can run it.

## Having the Proper Rights to Assign Security Group Access

The owner of the task has the right to assign access to a task to specific security groups.  However, the task’s owner must also have rights to those groups.

For example, a task owner must have access to the Front Office group to give it rights to run a task.  Otherwise, the owner will not see name of the group in the pick list from which the group is selected.

If the task owner has Administrator privileges and encounters this problem, it problem can be solved as follows:

Open the AVS window.
Select a task.
Select Script à Task Editor. 
The Task Editor window displays.
Select File à Properties.
The Task Properties window displays.
Right-click on the “Groups” field.
A pick list of all groups to which the user has access will display.
Scroll down to the group to be selected.
Click the Save button.
The user will be prompted to confirm the changes before the System saves them.

Navigate to Reference Explorer Personnel (V10.0r2 and later) or Reference Personnel Listing (V10.2.1 and earlier).
Double click on your user name.
The Personnel Editor window displays.
Query for the Group’s owner
Click the Security Groups radio button.
In the “Available Groups” field, select the security group to be added.
Click on the group name and click the Add button.
Select File à Save.
Go back to the Main Menu and click the Refresh button.
Close and re-enter the Task Editor.
The added security group(s) should appear in the picklist from which they are selected.
