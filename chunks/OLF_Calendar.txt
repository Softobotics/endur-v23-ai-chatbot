# Calendar

## Overview

The Calendar allows you to view different system holiday schedules, date sequences, and roll conventions. The holiday schedules displayed in the calendar are the ones entered into Holiday Schedule window of the Administration Manager.  Users can select any date sequence, holiday schedule or roll convention stored in the System, which will display all their relevant dates on the calendar. This window also allows users to double click on a specific date and retrieve all details about that date that have been entered into the System.

Note that a callback has been added to update the calendar if the current date is changed elsewhere in the application.

Optionally, two environment variables can be set to display additional fields and information on the Calendar window. By default, the variables are set to False. When set to True, these variables enable the functionality described in the table below:

## Setting up The Calendar

1.   Move the cursor to the Date Picker field. The default value for this field is the current system month and year. Select a month and year by using the left (back) and right (forward) arrows in the scroll bar or enter the desired month and year into the field and Click Enter.

2.   Click the Holiday field and select a holiday schedule from the popup list.  Click OK.

3.   Click the Date Sequence field and select a date sequence from the popup list.  Click OK.

4.   Click the Roll Convention field and select a roll convention from the popup list. Click OK.

5.   Check Show Days from Today to display financial business days and actual days between the selected date and the current date in the calendar (This will only be available if the AB_CALENDAR_SHOW_DAYS_FROM_TODAY environment variable described above is set to True).

6.   Check Show Julian Dates to display Julian dates in the calendar. (This will only be available if the AB_CALENDAR_SHOW_JULIAN_DATES environment variable described above is set to True).

7.   Check Jump to activate calendar jumps to supplied Julian Date and Date String dates. (This will only be available if the AB_CALENDAR_SHOW_JULIAN_DATES environment variable described above is set to True).

8.    Examine the lower panel of the Calendar window. The criteria specified in the top panel displays the appropriate holidays, date sequences and options for the selected month in the lower panel.

## Viewing Date Details on the Calendar

If you double-click on a particular day, you will see details about what holidays and date sequences are applicable for that date.  This is useful if there are too many to see on the main screen.
