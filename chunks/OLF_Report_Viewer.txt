# Report Viewer

## Overview

The Report Viewer allows users to view and print all reports that have been generated in the system.  Historical reports can also be viewed by changing the report date.  The system stores all reports to a specific file for a specific date.

## Accessing This Window/Screen

To access this window:

1. Start the Operations Manager.
1. Select the Daily Operations tab.
1. Click the Report Viewer icon .
1. The following window displays:
![image007](OLF_Report_Viewer_files/image002.jpg)

### Other Ways to Access This Window/Screen

Option 1: From any Query window, select Misc à View Report.

Option 2: From the Trading Manager, select View à Report Viewer.
