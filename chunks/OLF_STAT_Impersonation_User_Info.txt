The Scenario Test Activity Impersonation 
 User Info screen allows to store password for the users that can be 
 impersonated. The passwords are not displayed as open text. While the 
 password is typed in, only several characters are signaled. The passwords 
 are stored in the database as encrypted strings. Provided “Test” button 
 validates each user impersonation credentials in order to correct potential 
 issues with execution of the actual test cases, which use impersonation 
 that could be due to wrong password, security and personnel configuration.

## Accessing this Window

Note:   There are multiple 
 ways to access this window; however, only one way is defined because some 
 features can only be accessed via this procedure.

1.      From 
 OpenLink Central, right-click anywhere on the header and select Launch 
 Available Services. The Launch Available Services window displays.

2.      Type 
 Scenario 
 Test Activity Impersonation User Info in the Filter 
 Service field, highlight Scenario Test 
 Activity Impersonation User Info in the Available Services 
 panel, and then click Launch.
