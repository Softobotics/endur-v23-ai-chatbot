# System Monitor - Diagnostics - OPING

## Overview

This tab provides the ability to diagnose communications between modules/processes for the server/database logged into.

This window consists of the Oping Filters panel and the Oping Data Table panel. The filters panel contains fields that can be utilized in filtering the results that are shown in the data table.
