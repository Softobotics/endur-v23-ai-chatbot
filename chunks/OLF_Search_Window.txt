# SEARCH WINDOW

## Overview

The Search window allows users to specify which columns in the Table Viewer will be searched, the search key, and how search will be conducted.

## Accessing This Window/Screen

This window is accessed from the Table Viewer, which is used by several functionalities in the system. For illustration purposes, the following is an example of how it is accessed:

1. Start the Trading Manager.
1. Select Misc à Registered Pricing Models. The Registered Pricing Models window displays.
1. Select Search à Find.
1. The following window displays:
![image002](OLF_Search_Window_files/image001.jpg)
