# System Monitor - System - DLL Versions

## Overview

This screen shows detailed information about DLL versions used by the system, including the branch/tag they were built from and when the build was generated. This screen can be used to identify in which release specific DLLs were added. The information contained in this window is significant to the trouble-shooting process, specifically in diagnosing inconsistencies in dll versions.

See System Monitor
